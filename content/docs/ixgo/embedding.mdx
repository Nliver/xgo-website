---
title: Use adapters and memoization in embedded iXGo
description: Call an interpreted closure from a Go host, enable a standard-library direct-call adapter, and compare recursive results with memoization enabled and disabled.
---

Build a Go host that calls a stateful function returned by an iXGo script. Then run a recursive function in two interpreter contexts to see how the host controls memoization. Use Go 1.26 or 1.27 and the iXGo revision shown below.

In an empty directory, initialize the module.

```sh
go mod init example.com/ixgohost
go get github.com/goplus/ixgo@61dfa28e05d30b5e60b3cfa83b3c79e870cd629e
```

## Call a standard-library function and return a closure

Save the following program as `main.go`. It loads a Go script from a string. The host reads the interpreted `Label` result and calls the interpreted `Counter` closure twice.

```go title="main.go"
package main

import (
	"fmt"
	"log"

	"github.com/goplus/ixgo"
	_ "github.com/goplus/ixgo/directcall/strings"
	_ "github.com/goplus/ixgo/pkg/strings"
)

type intFunc struct {
	ixgo.DirectFuncVal
}

func (f intFunc) call(n int) int {
	return f.Call(n).(int)
}

func main() {
	ixgo.RegisterDirectFuncFor(func(value ixgo.DirectFuncVal) func(int) int {
		return intFunc{value}.call
	})

	const script = `package main

import "strings"

func Label() string {
	return strings.TrimSpace("  ready  ")
}

func Counter() func(int) int {
	total := 0
	return func(step int) int {
		total += step
		return total
	}
}

func main() {}
`

	program, err := ixgo.NewContext(0).LoadInterp("script.go", script)
	if err != nil {
		log.Fatal(err)
	}
	label, err := program.RunFunc("Label")
	if err != nil {
		log.Fatal(err)
	}
	callback, err := program.RunFunc("Counter")
	if err != nil {
		log.Fatal(err)
	}
	count := callback.(func(int) int)
	fmt.Println(label)
	fmt.Println(count(2))
	fmt.Println(count(3))
}
```

Run the host.

```sh
go mod tidy
go run .
```

```text
ready
2
5
```

The two blank imports have distinct roles. `pkg/strings` registers the standard-library package exports so interpreted code can import `strings`. `directcall/strings` registers Go adapters for supported operations such as `strings.TrimSpace`. To enable all bundled direct-call adapters, import `github.com/goplus/ixgo/directcall` and register the package exports your scripts use. `log` and `log/slog` retain their existing call path so logging can report the caller's file and line.

`RegisterDirectFuncFor` binds the exact `func(int) int` signature to a Go method value. Embed `ixgo.DirectFuncVal` as the receiver's first field. The bound method forwards its arguments to the interpreter and returns the result. Register adapters before loading scripts and keep the registration in place while any callback using it is live.

iXGo includes a built-in adapter for `func()`. A blank import of `github.com/goplus/ixgo/directfunc` adds common zero-argument signatures with one result, including `bool`, integer and floating-point types, `string`, and `error`. Other signatures and named function types use reflection unless the host registers their exact type.

## Control memoization per interpreter context

Memoization stores results or supported state changes so a later call can reuse them. The `ixgo` command enables the plugin by default. An embedded host enables it with a blank import of `github.com/goplus/ixgo/memo`. Pass `ixgo.DisableMemo` to `NewContext` to disable the plugin in one context.

Replace `main.go` with this program, then run `go mod tidy` and `go run .` again.

```go title="main.go" verify="go mod tidy && go run ."
package main

import (
	"fmt"
	"log"

	"github.com/goplus/ixgo"
	_ "github.com/goplus/ixgo/memo"
)

const script = `package main

func Fib(n int) int {
	if n < 2 {
		return n
	}
	return Fib(n-1) + Fib(n-2)
}

func main() {}
`

func fib(mode ixgo.Mode) int {
	program, err := ixgo.NewContext(mode).LoadInterp("fib.go", script)
	if err != nil {
		log.Fatal(err)
	}
	result, err := program.RunFunc("Fib", 20)
	if err != nil {
		log.Fatal(err)
	}
	return result.(int)
}

func main() {
	fmt.Println("memo enabled:", fib(0))
	fmt.Println("memo disabled:", fib(ixgo.DisableMemo))
}
```

```text
memo enabled: 6765
memo disabled: 6765
```

Both contexts return the same Fibonacci value. The plugin analyzes recursive calls before installing a cache. It supports pure scalar recursion and selected accumulator and receiver methods. Functions with external side effects or unsupported mutable state, and interpreter sessions using tracing or custom call interception, take the ordinary interpreter path. For floating-point cases the plugin uses exact bit patterns, preserving signed zeros and the original order of operations.
