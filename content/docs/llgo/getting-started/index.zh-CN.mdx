LLGo 是一个独立的编译器项目。你可以先使用普通 Go 包，再根据程序需求添加本机绑定或选择其他编译目标。

## 入门步骤

1. [安装 LLGo 和本机运行时依赖](/zh-CN/docs/llgo/getting-started/installation)。
2. [编译并运行 Go 包](/zh-CN/docs/llgo/getting-started/first-program)。
3. [检查选定的 Go 和 LLVM 环境](/zh-CN/docs/llgo/getting-started/environment)。
4. 从 [LLGo 编译器指南](/zh-CN/docs/llgo) 中选择专门的工作流。

前三步使用稳定版 `v1.0.10`。[工具链](/zh-CN/docs/llgo/toolchain)和[参考](/zh-CN/docs/llgo/reference)页面描述该版本支持的行为和选项。
