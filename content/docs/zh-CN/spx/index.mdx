在本机运行 SPX 的 Hello 游戏，修改 Calf 精灵显示的对白。SPX 是兼容 Scratch 的二维游戏引擎，项目由 `.spx` 类文件和素材目录组成。

## 准备运行时

安装 Git、Make、Go 和 XGo CLI，并确保 Go 的可执行文件目录在 `PATH` 中。Windows 使用 Git Bash 并安装 MinGW-w64。以下命令使用 SPX `v4.0.2` 及其配套运行时，该发行版锁定的构建工具链包含 Go 1.26.5 和 XGo 1.7.5。

```sh
git clone --branch v4.0.2 --depth 1 https://github.com/goplus/spx.git
cd spx
make setup
make doctor
```

`make setup` 下载当前平台的运行时并安装 `spx` 命令。`make doctor` 可查看项目识别到的平台、运行时和工具链配置。

## 运行 Hello 并修改 Calf 的对白

从源码根目录进入 Hello 教程。

```sh
cd tutorial/00-Hello
xgo run .
```

游戏窗口会显示 Calf 以及对白 `Hello XGo`。在 `assets/index.json` 的 `zorder` 中可以找到 Calf 的绘制顺序。打开 `Calf.spx` 找到启动事件。

```xgo title="Calf.spx"
onStart => {
    say "Hello XGo"
}
```

关闭游戏窗口，修改引号里的文字，重新运行 `xgo run .` 即可查看变化。要使用浏览器编辑，参阅 [XBuilder 游戏预览](/zh-CN/docs/xbuilder)。

## 运行事件、状态与动画教程

在对应目录中运行 `xgo run .`。

| 目录 | 任务 | 可以观察的行为 |
| --- | --- | --- |
| `tutorial/01-Weather` | 跟踪 `broadcast` 和 `onMsg`。 | Kai 和 Jaime 通过互发消息展开对话。 |
| `tutorial/02-Dragon` | 找到显示精灵变量 `score` 的舞台监视器。 | Dragon 碰到 Shark 时，分数会变化。 |
| `tutorial/03-Clone` | 比较各个克隆自己的 `id` 与共享的 `gid`。 | 点击 Calf 创建克隆，点击箭头移除最近的克隆。 |
| `tutorial/04-Bullet` | 跟踪一个克隆从创建到清理的过程。 | 游戏运行时会生成临时的子弹精灵。 |
| `tutorial/05-Animation` | 查看素材中的造型序列。 | 精灵播放动画时会切换造型。 |

在 Weather 教程中，`Kai.spx` 的启动事件处理器广播消息 `1`。`Jaime.spx` 中的 `onMsg "1"` 处理器收到消息后，广播消息 `2`。`Kai.spx` 中的 `onMsg "2"` 处理器接着回应。精灵文件在语言层的行为见[类文件规范](/zh-CN/docs/toolchain/classfile-specification)。

要新建自己的项目，请参阅 [SPX 命令行工作流](/zh-CN/docs/spx/cli)。要给角色动画添加音效，请参阅 [SPX 动画音效指南](/zh-CN/docs/spx/animation-audio)。
