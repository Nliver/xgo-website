## 查看项目

```sh
git clone https://github.com/goplus/MazePlay.git
cd MazePlay
git checkout --detach 48b33bae8adeed19d07d982768e2e5edabda9a14
```

阅读 `main.spx` 了解共享游戏状态，再打开 `Calf.spx` 查看精灵的事件处理程序。请将 `assets/` 目录与脚本放在一起。该项目当时的启动命令是 `gop run .`，需要兼容的 Go+ 工具链和图形桌面环境。此项目使用 SPX v1.1.0。当前的引擎和启动工具见 [SPX 指南](/zh-CN/docs/spx)。

## 跟踪事件

每个方向键处理程序都让小牛沿一个坐标轴移动三个单位。另一个启动处理程序在循环中检查碰撞。碰到迷宫时会播放碰撞音效，并让小牛回到 (−204, 145)。碰到 Red 时会显示“You win”，等待三秒后退出。

对照右方向键处理程序与碰撞检测循环。前者只改变 x 坐标。后者检查新位置，每次检查之间等待 0.03 秒。
