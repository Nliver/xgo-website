## 查看项目

```sh
git clone https://github.com/goplus/FlappyCalf.git
cd FlappyCalf
git checkout --detach 4ee62694ef952b51f03938ccbd969c1083c40256
```

阅读 `main.spx` 了解共享游戏状态，再打开 `Pipe.spx` 查看精灵的事件处理程序。请将 `assets/` 目录与脚本放在一起。该项目当时的启动命令是 `gop run .`，需要兼容的 Go+ 工具链和图形桌面环境。此项目使用 SPX v1.1.0。当前的引擎和启动工具见 [SPX 指南](/zh-CN/docs/spx)。

## 跟踪事件

点击消息启动计时器。1.5 秒后，只要小牛仍存活，管道就会每隔 2.8 秒生成一个克隆。一个克隆处理程序让管道从 x = 250 向左移动。另一个处理程序在游戏进行时等待 x 小于 −80，给分数加一，然后退出循环。

打开 `Calf.spx`，找到处理点击的代码。按空格键或鼠标会让小牛上升。如果碰到管道或上边缘，或者 y 坐标低于 −123.9，程序就会设置死亡标志，并广播游戏结束消息。
