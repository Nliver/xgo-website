---
title: 为 SPX 动画绑定音效
description: 在角色的资源配置中设置单次和随动画循环的音效，并比较不同周期下的播放表现。
---

用 SPX `v4.0.2` 仓库中的动画音频示例，对比单次音效与跟随动画周期的音效。安装 [SPX 第一个游戏](/zh-CN/docs/spx) 所用的运行时，然后在仓库根目录运行以下命令。

```sh
spx run --path test/AnimationOnStartOnPlayAudio
```

Monkey 角色会先播放 `clapTruncate`。按 **F** 重新开始短周期动画，按 **G** 切到较长的周期，按 **S** 停止动画。短周期会在掌声音效结束前重新播放它。较长的周期让掌声在一个周期内播完并重复。

## 查看角色配置

打开 `test/AnimationOnStartOnPlayAudio/assets/sprites/Monkey/index.json`。其中 `fAnimations` 下的 `clapTruncate` 条目指定了帧范围、帧率和音效绑定。

```json title="index.json"
{
  "frameFps": 20,
  "frameFrom": 42,
  "frameTo": 51,
  "onStart": { "play": "chomp" },
  "onPlay": { "play": "clap" }
}
```

两个 `play` 的值都是音效名称。示例分别在项目资源的 `sounds/chomp/index.json` 和 `sounds/clap/index.json` 声明这两个名称。在自己的项目中绑定音效时，请将音效声明及对应的音频文件保留在项目的资源目录下。

- `onStart.play` 在播放开始时触发一次音效，之后每轮循环开始时再触发一次。
- `onPlay.play` 启动归属该动画播放的循环音效。新一轮动画开始时，音效会从头播放。停止或换掉动画时，这段绑定的播放也会停止。

## 对比两种时长

短动画以每秒 20 帧播放 10 帧，周期为半秒。`clapComplete` 的结束帧为 67，帧率相同，周期为 1.3 秒。可先复制一份示例，只修改 `clapTruncate` 的 `frameTo`，再运行并对比原版中的掌声音效。两个音效绑定保持相同，变化的是重新播放的间隔。
