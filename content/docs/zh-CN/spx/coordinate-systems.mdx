SPX 游戏逻辑使用类似 Scratch 的世界坐标系。舞台中心是 `(0, 0)`，正 `x` 轴指向右方，正 `y` 轴指向上方。公开的精灵位置、移动方法、舞台边界和碰撞逻辑都使用这套坐标。

## 分开管理不同坐标空间

一个项目可能涉及多个坐标空间。

- **世界坐标**描述精灵和舞台的逻辑位置。
- **素材坐标**描述图像像素、造型锚点和导入的碰撞路径。
- **局部渲染坐标**描述相对于精灵或造型原点的几何位置。
- **画布坐标**属于渲染后端，纵轴通常向下。

值跨越边界时进行转换。将游戏状态存储在一个规范坐标空间中，只把转换后的值传给使用方。

## 使用世界坐标放置精灵

下面的舞台脚本在放置精灵和设置摄像机时都使用世界坐标。

```xgo title="main.spx"
onStart => {
    Calf.setXYpos 120, 80
    Camera.setXYpos 0, 0
}
```

不要给 `Calf.setXYpos` 额外加摄像机偏移。摄像机改变视图，精灵位置仍然是世界坐标。

## 处理输入和碰撞

SPX 暴露的鼠标坐标已经使用舞台坐标。精灵跟随指针时可以直接使用这些值。

```xgo title="pointer.spx"
onStart => {
    forever {
        setXYpos mouseX, mouseY
        wait 0.03
    }
}
```

碰撞几何体仍然相对于造型或精灵原点。将形状附加到物理实体时，引擎会应用精灵的世界坐标平移。

## 排查坐标错误

当移动或碰撞出现偏移时，检查原点、`y` 轴方向，以及摄像机或造型锚点是否已经应用过。使用非零位置，并配合旋转或不对称的造型进行测试，可以观察到重复平移。

图像格式和动画素材见 [SPX 动画与音效](/zh-CN/docs/spx/animation-audio)以及上游素材文档。
