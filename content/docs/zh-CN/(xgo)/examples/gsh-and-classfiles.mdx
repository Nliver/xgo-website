## 向子命令传递环境变量

在 `demo/gsh-exec` 中运行。

运行示例前，确保 `FOO` 尚未设置。脚本会调用相邻目录中的 XGo 程序五次，其中第三次和第四次会设置 `FOO`。随后脚本会列出用户主目录的内容两次，最后几行输出因机器而异。

### exec.gsh

```xgo
xgo "run", "./foo"
exec "xgo run ./foo"
exec "FOO=100 xgo run ./foo"
exec {"FOO": "101"}, "xgo", "run", "./foo"
exec "xgo", "run", "./foo"
exec "ls $HOME"
ls ${HOME}
```

### foo/foo.xgo

```xgo
import "os"

foo := os.getenv("FOO")
if foo != "" {
	echo foo
} else {
	echo "FOO not found"
}
```

```sh
(unset FOO; xgo run exec.gsh)
```

子进程会在列出目录内容前输出以下各行。

```text
FOO not found
FOO not found
100
101
FOO not found
```
