### 复合字面量

复合字面量每次求值都会构造一个新的复合值。写法为字面量的类型后接一对花括号，括号中列出元素。每个元素前可以指定相应的键。

```text
CompositeLit  = LiteralType LiteralValue .
LiteralType   = TypeName [ TypeArgs ] .
LiteralValue  = "{" [ ElementList [ "," ] ] "}" .
ElementList   = KeyedElement { "," KeyedElement } .
KeyedElement  = [ Key ":" ] Element .
Key           = FieldName | Expression | LiteralValue .
FieldName     = identifier .
Element       = Expression | LiteralValue .
```
字面量类型 LiteralType 的底层类型 `T` 必须为[结构体](#结构体类型)类型或[类文件](/zh-CN/docs/toolchain/classfile-specification)类型。元素和键的类型须满足相应字段的赋值要求，不进行额外转换。不能多次指定同一字段。

* 键必须是结构体类型中声明的字段名。
* 不使用键时，元素列表必须按字段声明顺序为每个字段提供一个元素。
* 只要有一个元素使用键，就必须为所有元素指定键。
* 使用键时可以省略部分字段。省略字段取其类型的零值。
* 可以完全省略元素列表，这样得到的值是该类型的零值。
* 不能为其他包中结构体的未导出字段指定元素。

给定以下声明：

```xgo
type Point3D struct { x, y, z float64 }
type Line struct { p, q Point3D }
```
可以写成：

```xgo
origin := Point3D{}                            // zero value for Point3D
line := Line{origin, Point3D{y: -4, z: 12.3}}  // zero value for line.q.x
```
对复合字面量[取地址](#地址运算符)，得到的指针指向一个独立的变量，该变量以字面量的值初始化。

```xgo
var pointer *Point3D = &Point3D{y: 1000}
```
当使用类型名形式的复合字面量作为操作数，出现在 `if`、`for` 或 `switch` 关键字与语句块左花括号之间，且该字面量未被圆括号、方括号或花括号包围时，会产生解析歧义。这种情况下，解析器可能把字面量的左花括号当作语句块的起点。需要使用圆括号消除歧义。

```xgo
if x == (T{a,b,c}[i]) { … }
if (x == T{a,b,c}[i]) { … }
```

```xgo
)
```

### 结构体类型

结构体由一系列称为字段的命名元素组成，每个字段都有名称和类型。字段名可以显式声明（IdentifierList），也可以通过嵌入字段隐式给出（EmbeddedField）。同一结构体中，非空白字段名必须[唯一](/zh-CN/docs/reference/mini-specification#标识符的唯一性)。

```text
StructType    = "struct" "{" { FieldDecl ";" } "}" .
FieldDecl     = (IdentifierList Type | EmbeddedField) [ Tag ] .
EmbeddedField = [ "*" ] TypeName [ TypeArgs ] .
Tag           = string_lit .
```
```xgo
// An empty struct.
struct {}

// A struct with 6 fields.
struct {
	x, y int
	u float32
	_ float32  // padding
	A *[]int
	F func()
}
```
只声明类型而未显式指定字段名的字段称为*嵌入字段*。它可以写作类型名 T，也可以写作指向非接口类型的指针 *T，T 本身不能是指针类型。字段名取不含包限定符的类型名。

```xgo
// A struct with four embedded fields of types T1, *T2, P.T3 and *P.T4
struct {
	T1        // field name is T1
	*T2       // field name is T2
	P.T3      // field name is T3
	*P.T4     // field name is T4
	x, y int  // field names are x and y
}
```
下面的声明不合法，因为同一结构体中的字段名必须唯一。

```xgo
struct {
	T     // conflicts with embedded field *T and *P.T
	*T    // conflicts with embedded field T and *P.T
	*P.T  // conflicts with embedded field T and *T
}
```
如果结构体 `x` 的嵌入字段上存在字段或方法 `f`，并且选择器 `x.f` 能合法地引用它，就称 `f` 被提升。

提升字段的使用方式与普通字段相同，但不能作为该结构体[复合字面量](#复合字面量)中的字段名。

给定结构体类型 `S` 和[命名类型](#类型) `T`，提升方法按以下规则纳入方法集。

* 若 `S` 包含嵌入字段 `T`，则 `S` 与 `*S` 的[方法集](/zh-CN/docs/reference/mini-specification#方法集)都包含接收者为 `T` 的提升方法。`*S` 的方法集还包含接收者为 `*T` 的提升方法。
* 若 `S` 包含嵌入字段 `*T`，则 `S` 与 `*S` 的方法集都包含接收者为 `T` 或 `*T` 的提升方法。

字段声明之后可以添加字符串字面量作为*标签*，同一条声明中的所有字段共用该标签。空字符串等同于没有标签。标签可通过反射读取，并参与结构体的[类型标识](/zh-CN/docs/reference/mini-specification#类型标识)判定，在其他情况下忽略。

```xgo
struct {
	x, y float64 ""  // an empty tag string is like an absent tag
	name string  "any string is permitted as a tag"
	_    [4]byte "ceci n'est pas un champ de structure"
}

// A struct corresponding to a TimeStamp protocol buffer.
// The tag strings define the protocol buffer field numbers;
// they follow the convention outlined by the reflect package.
struct {
	microsec  uint64 `protobuf:"1"`
	serverIP6 uint64 `protobuf:"2"`
}
```
如果中间只经过数组类型或结构体类型，结构体类型 `T` 的字段不能直接或间接包含 T 本身。

```xgo
// invalid struct types
type (
	T1 struct{ T1 }            // T1 contains a field of T1
	T2 struct{ f [10]T2 }      // T2 contains T2 as component of an array
	T3 struct{ T4 }            // T3 contains T3 as component of an array in struct T4
	T4 struct{ f [10]T3 }      // T4 contains T4 as component of struct T3 in an array
)

// valid struct types
type (
	T5 struct{ f *T5 }         // T5 contains T5 as component of a pointer
	T6 struct{ f func() T6 }   // T6 contains T6 as component of a function type
	T7 struct{ f [10][]T7 }    // T7 contains T7 as component of a slice in an array
)
```

#### 使用花括号构造元组

除函数式构造外，元组还支持使用花括号初始化，通过 `:` 为字段赋值。

```xgo
type Point (x int, y int)

p1 := Point{x: 10, y: 20}
p2 := Point{10, 20}
```
#### 花括号中的匿名元组字面量

使用花括号构造复合字面量时，也可以在其中嵌入元组字面量。

```xgo
// Using tuples in struct fields
type Record struct {
	coords (int, int)
	data   (string, bool)
}

r := Record{
	coords: (10, 20),
	data:   ("test", true),
}
```
#### 类型兼容性与反射

运行时，元组用结构体表示，字段名依次为 `X_0`、`X_1`、`X_2` 等。

```xgo
type Point (x int, y int)

// At runtime, Point is equivalent to:
// struct {
//     X_0 int  // accessible as .x or .0 at compile time, .X_0 at runtime
//     X_1 int  // accessible as .y or .1 at compile time, .X_1 at runtime
// }
```
元素类型与顺序都相同的命名元组具有相同的底层结构，不同的类型定义仍会产生不同的类型。

```xgo
type Point (x int, y int)
type Coord (a int, b int)

// Point and Coord have identical underlying types but are different types
// Conversion is required: c := Coord(p)
```

##### comparable 接口

预声明接口 `comparable` 的类型集包含所有严格可比较的非接口类型。这些类型的值可以用 `==` 和 `!=` 比较。严格可比较的详细条件见下文。

`comparable` 主要在泛型代码中用作类型约束，不能用作变量或结构体字段的类型。

```xgo
// Example: using comparable as a type constraint
func Find[T comparable](slice []T, value T) int {
	for i, v := range slice {
		if v == value {
			return i
		}
	}
	return -1
}
```
以下类型严格可比较。
- 布尔类型、数值类型和字符串类型。
- 指针类型。
- 通道类型。
- 元素类型严格可比较的数组。
- 所有字段类型都严格可比较的结构体。

切片、映射和函数类型不可比较，不能作为满足 `comparable` 的具体类型。

#### 比较运算符

见[比较运算符](/zh-CN/docs/reference/mini-specification#比较运算符)。

相等运算符 `==` 和 `!=` 可用于可比较类型的操作数。顺序运算符 `<`、`<=`、`>`、`>=` 可用于有序类型的操作数。这些术语与比较结果的定义如下。

* 通道类型可比较。两个通道由同一次 [make](/zh-CN/docs/reference/mini-specification#长度和容量) 调用创建，或者都为 `nil` 时，它们相等。
* 如果所有字段类型都可比较，结构体类型就可比较。两个结构体中对应的非[空白](/zh-CN/docs/reference/mini-specification#空白标识符)字段值都相等时，结构体值相等。字段按源码顺序比较，遇到不相等的字段或完成所有比较时停止。
* 类型参数严格可比较时，它也可比较，具体条件见下文。

```xgo
const c = 3 < 4            // c is the untyped boolean constant true

type MyBool bool
var x, y int
var (
	// The result of a comparison is an untyped boolean.
	// The usual assignment rules apply.
	b3        = x == y // b3 has type bool
	b4 bool   = x == y // b4 has type bool
	b5 MyBool = x == y // b5 has type MyBool
)
```
一个类型可比较，且它本身和它的组成部分都不是接口类型时，称为*严格可比较*。具体规则如下。

* 布尔、数值、字符串、指针和通道类型严格可比较。
* 所有字段类型都严格可比较时，结构体类型严格可比较。
* 元素类型严格可比较时，数组类型严格可比较。
* 类型集中的所有类型都严格可比较时，类型参数严格可比较。
