---
title: 计算大整数和精确分数
description: 用 r 后缀、bigint 和 bigrat 进行精确的整数和有理数运算。
---

计算一个超出 64 位整数范围的值，再精确地相加两个分数。将下面两个程序分别保存为对应的文件，用 XGo 运行。

## 给大整数加一

`1r` 这样的字面量默认具有 `bigint` 类型，表示任意精度整数。将它左移 80 位，再加一。

```xgo title="big-count.xgo"
count := 1r << 80
echo count
echo count + 1
```

运行 `xgo run big-count.xgo`。

```text
1208925819614629174706176
1208925819614629174706177
```

第一行是 2 的 80 次幂。两行都保留了精确的整数值。

## 相加分数并控制除法结果

`1/3r` 这样的字面量是有理数常量。也可以先将整数显式转换为 `bigrat` 再做除法。

```xgo title="fractions.xgo"
total := 1/3r + 1/6r
whole := 1r
echo total
echo whole / 3
echo bigrat(whole) / 3
```

运行 `xgo run fractions.xgo`。

```text
1/2
0
1/3
```

第二行是整数除法的结果。在除法前转换 `whole` 的类型，就得到第三行的精确分数。
