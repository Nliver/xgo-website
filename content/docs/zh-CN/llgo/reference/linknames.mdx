---
title: 使用 LLGo linkname 命名空间
description: 使用 LLGo 的 linkname 规则绑定 C、Windows、Python、LLVM 和编译器符号。
---

LLGo 为 `go:linkname` 扩展了命名空间，用来指定声明所用的 ABI 或编译器功能。

| 命名空间 | 用途 |
| --- | --- |
| `C.` | C 和 C++ ABI 符号 |
| `stdcall.` | Windows stdcall 符号 |
| `py.` | Python 函数和值 |
| `llgo.` | LLGo 编译器指令 |
| `llvm.` | 经签名校验的 LLVM 内建函数 |

## 导入本机符号

绑定外部 C 函数时，声明一个不带函数体的 Go 函数原型。对 C 函数使用其 C 标识符，对 C++ 函数使用目标文件中经过名称改编的符号名。

```go title="linkname.go" verify="manual"
import _ "unsafe"

//go:linkname Sqrt C.sqrt
func Sqrt(x float64) float64
```

## 将 Go 实现导出给 C

给 `C.` 声明补上函数体即可定义 C 入口。LLGo 会生成原生线程进入 Go 时所需的运行时衔接代码。下面的例子让 C 代码可以调用 `add_ints`，其参数和返回值均为有符号的 32 位整数。

```go title="linkname.go" verify="manual"
//go:linkname addInts C.add_ints
func addInts(a, b int32) int32 { return a + b }
```

变量声明中的 `C.` 引用由原生库持有的存储空间。Go 声明应指定变量类型并省略初始值。要让 C 访问由 Go 持有的状态，请导出访问函数。

## 绑定方法或 Python 函数

使用 `//llgo:link T.Method C.symbol` 绑定 Go 方法。C 函数将接收者作为第一个参数。该指令要求 Go 方法带有函数体。LLGo 会调用绑定的符号，标准 Go 编译器构建的程序仍可执行方法体。

在每个包中用一处声明指定绑定的 Python 模块，例如 `const LLGoPackage = "py.math"`。绑定到 `py.sqrt` 的函数原型会解析该模块的 `sqrt` 属性。完整程序见 [Python 教程](/zh-CN/docs/llgo/tutorials/python)。

## 绑定 LLVM 操作

下面的 `llvm.ctlz` 计算前导零位数。Go 函数原型选用 32 位重载。LLVM 要求第二个参数是常量，传入 `false` 时，输入为零的结果明确定义为 32。

```go title="linkname.go" verify="manual"
//go:linkname ctlz32 llvm.ctlz
func ctlz32(x uint32, zeroIsPoison bool) uint32

func LeadingZeros32(x uint32) uint32 { return ctlz32(x, false) }
```

要把此操作作为函数值使用，或在 `go`、`defer` 语句中调用，请使用上面的普通 Go 包装函数。它会在调用内建函数时传入所需的常量。LLGo 支持部分内建函数系列，并根据构建编译器时使用的 LLVM 版本校验签名。
