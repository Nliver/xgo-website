---
title: 使用 LLGoFiles 附加原生源文件
description: 将 C 和 C++ 包装代码保存在普通文件中，并随 LLGo 包一起编译。
---

如果包中的原生源文件需要由 C 或 C++ 工具直接处理，可以使用 `LLGoFiles`。它是一个包级字符串常量。LLGo 会编译其中列出的文件，并将生成的目标代码链接到包中。

## 添加 C 包装代码

按以下结构创建一个包。按照惯例，`_wrap` 目录用于存放与 Go 声明一同维护的本机代码，标准 Go 工具会跳过该目录。

```files
embind/
├── embind.go
└── _wrap/
    └── add.c
```

在 `embind.go` 中声明原生文件，并通过 `go:linkname` 绑定文件中的符号。

```go title="embind/embind.go" verify="manual"
package embind

import _ "unsafe"

const LLGoFiles = "_wrap/add.c"

//go:linkname add C.add32
func add(a, b int32) int32

func Add(a, b int32) int32 {
    return add(a, b)
}
```

将 C 实现写入 `_wrap/add.c`。

```c title="embind/_wrap/add.c" verify="manual"
#include <stdint.h>

int32_t add32(int32_t a, int32_t b) {
    return a + b;
}
```

在 Go 或 XGo 程序中导入 `embind`，并使用 `llgo build` 构建程序。LLGo 会根据文件扩展名选择原生编译器，并将编译结果链接到包中。

## 列出多个文件

用分号分隔原生源文件路径。每条路径都相对于 Go 包目录。

```go title="embind/embind.go" verify="manual"
const LLGoFiles = "_wrap/emval.cpp;_wrap/emval_helpers.cpp"
```

如果列出的文件共用一组选项，可以添加一个编译器选项段。选项段可以包含固定选项，也可以使用受限的 `$(pkg-config ...)` 或 `$(llvm-config ...)` 查询。

```go title="embind/embind.go" verify="manual"
const LLGoFiles = "-I./_wrap/include:_wrap/emval.cpp;_wrap/emval_helpers.cpp"
```

第一个冒号之前是选项段。请使用适合宿主平台的路径和选项。

## 从系统查询编译选项

在构建时，选项段可以调用 `pkg-config` 或 `llvm-config` 查询编译选项。

```go title="embind/embind.go" verify="manual"
const LLGoFiles = "$(pkg-config --cflags libffi):_wrap/libffi.c"
```

LLGo 的命令替换只支持这两种用于查询构建信息的命令。

## 按平台选择文件

使用 Go 的常规构建约束来选择特定平台的声明。

在 `embind_linux.go` 中编写 Linux 版本的声明。

```go title="embind/embind_linux.go" verify="manual"
//go:build linux

package embind

const LLGoFiles = "$(pkg-config --cflags libffi):_wrap/libffi_linux.cpp"
```

在 `embind_darwin.go` 中编写 macOS 版本的声明。

```go title="embind/embind_darwin.go" verify="manual"
//go:build darwin

package embind

const LLGoFiles = "_wrap/libffi_darwin.mm"
```

有关直接声明、调用约定以及 C 和 C++ 类型映射，请参阅[调用约定](/zh-CN/docs/llgo/reference/calling-conventions)。
