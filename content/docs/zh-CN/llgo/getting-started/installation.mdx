---
title: 安装 LLGo
description: 安装发行版编译器，并准备加载 Go 包和链接原生程序所需的环境。
---

本例使用 LLGo `v1.0.10` 和 Go 1.27。下载与操作系统和处理器匹配的发行包，解压后将其中的 `bin` 目录加入 `PATH`。保留发行包的完整目录结构，以便 LLGo 找到运行时。Go 工具链也需要在 `PATH` 中，以便加载模块和包。[v1.0.10 发行包](https://github.com/xgo-dev/llgo/releases/tag/v1.0.10)

在 macOS 和 Linux 上，使用独立发行包还需要本机 C 工具链、`pkg-config` 以及 8.2 或更高版本的 Boehm 垃圾回收库（BDWGC）。

<TabsContent value="macos">

**macOS**

Homebrew 提供的 Boehm 垃圾回收库包名为 `bdw-gc`。也可以用下列命令直接安装 LLGo。Homebrew 中的软件包可能先于本指南更新，安装后请检查实际版本。

```sh
brew install llgo
```

</TabsContent>
<TabsContent value="linux">

**Linux**

在 Debian 或 Ubuntu 上，安装 `libgc-dev` 和 `pkg-config`。独立的 LLGo 发行包还需要 Clang 和本机链接器。

```sh
sudo apt-get install libgc-dev pkg-config
```

</TabsContent>

<TabsContent value="windows">

解压与主机架构对应的 ZIP（`386`、`amd64` 或 `arm64`），并将其中的 `bin` 目录加入 `PATH`。该发行包同时支持 MSVC 和 MinGW。使用 MSVC 时，请在 Visual Studio 开发人员命令行中准备对应的 Windows SDK 和 vcpkg 库。使用 MinGW 时，请选择匹配的 LLVM 工具链和库。确保头文件、导入库、运行时 DLL 和 pkg-config 元数据对应同一种 ABI 和处理器架构。[v1.0.10 的 Windows 配置说明](https://github.com/xgo-dev/llgo/blob/v1.0.10/WINDOWS.md)

```powershell
clang -dumpmachine
pkg-config --modversion bdw-gc libffi
llgo version
```

</TabsContent>

</Tabs>

在 macOS 或 Linux 上，运行 `pkg-config --libs bdw-gc` 检查链接器参数。随后在终端中查看实际安装的 LLGo 版本。

```sh
llgo version
```
