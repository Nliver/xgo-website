在浏览器中创建一个游戏，让精灵开场说出一句话。XBuilder 是使用 SPX 构建游戏的编辑器。

## 创建项目并预览

1. 打开 [XBuilder](https://xbuilder.com) 并登录。在 **New project…** 中创建 SPX 项目。
2. 从精灵面板的素材库添加一个精灵，选中它，打开对应的脚本。
3. 将以下代码加入精灵脚本。如果脚本已有 `onStart`，把 `say` 那一行放进已有的处理函数。

```xgo title="sprite.spx"
onStart => {
    say "Hello from XBuilder", 2
}
```

选择 **Run**。精灵会显示内容为 `Hello from XBuilder` 的气泡，持续两秒。选择 **Stop** 返回编辑。预览失败时，可以在控制台查看运行错误，或检查代码编辑器标出的位置。

## 找到对应的编辑面板

一个项目有一个舞台。舞台脚本管理精灵共享的逻辑，舞台设置管理背景等属性。每个精灵各有自己的代码和造型。舞台和精灵都能播放项目中的声音。

使用预览测试当前编辑内容。使用项目保存操作将更改保存到云端。如果需要游戏内容的本地副本，请使用导出。向已有项目导入游戏文件时会替换其中的游戏内容，如需同时保留两个版本，请先导出当前内容。

## 设置摄像机位置和缩放

沿用上面的项目，把精灵留在舞台中心附近。在编辑器工具栏切换到**地图编辑模式**，把**地图尺寸**的宽和高都改为 1000。切回**默认模式**，选中舞台并打开**代码**。添加以下舞台脚本。如果舞台已有 `onStart`，就把两个摄像机调用加到已有的处理函数中。

```xgo title="main.spx"
onStart => {
    Camera.setXYpos 0, 0
    Camera.setZoom 2
}
```

选择 **Run**。摄像机以舞台坐标 `(0, 0)` 为中心放大画面。缩放为 2 时，480 × 360 的视口显示舞台中央 240 × 180 的区域。精灵的舞台坐标保持不变。选择 **Stop**，把缩放值改为 `1`，再运行一次，对比更大的可见区域。

在**地图编辑模式**中按舞台坐标布置精灵。屏幕上的控件使用视口坐标，随摄像机移动时仍保持在屏幕原位。`mouseX` 和 `mouseY` 已经使用舞台坐标，可以直接传给精灵的 `setXYpos` 方法。

有关游戏脚本和本地项目结构，请继续阅读 [SPX](/zh-CN/docs/spx)。
