The XGo Playground lets you try a program without installing XGo locally. The repository also links to shareable examples.

Open the Playground and enter the Hello World program.

```xgo
println "Hello world"
```

Run the program in the Playground. It should print `Hello world`.

[Open the XGo Playground](https://play.xgo.dev/)

For a local workflow with files and a toolchain you control, follow [Install XGo](/docs/getting-started/installation) and [Your first XGo program](/docs/getting-started/hello-world).
