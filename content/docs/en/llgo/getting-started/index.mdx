LLGo is a standalone compiler project. You can use it with ordinary Go packages first, then add native bindings or select a non-native target when the program needs them.

## Follow the beginner path

1. [Install LLGo and its native runtime prerequisites](/docs/llgo/getting-started/installation).
2. [Compile and run a Go package](/docs/llgo/getting-started/first-program).
3. [Inspect the selected Go and LLVM environment](/docs/llgo/getting-started/environment).
4. Choose a specialized workflow from the [LLGo compiler guide](/docs/llgo).

The first three pages use the stable `v1.0.10` release. Pages under [toolchain](/docs/llgo/toolchain) and [reference](/docs/llgo/reference) describe compiler behavior and supported options for that release.
