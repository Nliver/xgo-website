XGo is a programming language designed to make engineering, STEM education, and data science approachable. Its project vision is to enable everyone to become a builder of the world.

## One language across ecosystems

The project describes its ambition with this formula.

~~~text
XGo := C * Go * Python * JavaScript + Scratch
~~~

XGo keeps Go’s engineering foundation while providing concise syntax and bridges to C, C++, Python, and JavaScript ecosystems through the supported toolchains.

## Progressive complexity

A short XGo program can omit ceremony such as `package main` and `func main`. As a project grows, it can use packages, modules, Go files, XGo files, class frameworks, and the standard Go toolchain model.

The [first program tutorial](/docs/tutorials/first-program) starts with the smallest useful program. The [Go interoperability guide](/docs/interoperability/go) explains how a package can combine Go and XGo source files.

## Domain-friendly software

XGo favors specific domain friendliness. Classfiles and class frameworks abstract domain knowledge while keeping the language core reusable. See [XGo class framework](/docs/toolchain/classfiles) and [From DSLs to specific domain friendliness](/blog/xgo-design-philosophy).
