---
title: XGo 是什么？
description: XGo 的项目愿景、语言公式和它所连接的生态。
---

XGo 面向工程、STEM 教育和数据科学，旨在降低这些领域的编程门槛。项目的愿景是让每个人都能成为世界的创造者。

## 一门语言连接多个生态

项目用下面的公式表达这一愿景。

~~~text
XGo := C * Go * Python * JavaScript + Scratch
~~~

XGo 保留了 Go 的工程基础，同时提供简洁的语法，并通过支持的工具链连接 C、C++、Python 和 JavaScript 生态。

## 循序渐进的复杂度

简短的 XGo 程序可以省略 `package main` 和 `func main`。随着项目扩大，可以逐步引入包、模块、Go 和 XGo 源文件、类框架，以及标准 Go 工具链的开发方式。

[第一个程序教程](/zh-CN/docs/tutorials/first-program)从一个精简而完整的程序开始。[Go 互操作指南](/zh-CN/docs/interoperability/go)说明如何在同一个包中组合 Go 和 XGo 源文件。

## 面向特定领域的软件

XGo 重视对特定领域的支持。类文件和类框架用于提炼领域知识，语言核心仍可供不同领域复用。参见 [XGo 类框架](/zh-CN/docs/toolchain/classfiles)和[从领域专用语言到面向特定领域的设计](/zh-CN/blog/xgo-design-philosophy)。
