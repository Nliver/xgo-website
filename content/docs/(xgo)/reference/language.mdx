The XGo repository maintains two specifications. The Mini Specification describes the recommended syntax set. The Full Specification covers additional language features, including struct composite literals, and contains unfinished sections.

Use these references to find a rule and its examples. Each page records its upstream sources.

| Topic | Reference |
| --- | --- |
| Recommended syntax, lexical elements, and declarations | [Mini Specification](/docs/reference/mini-specification) |
| Additional syntax and Go compatibility | [Full Specification](/docs/reference/full-specification) |
| Commands and function calls | [Function call guide](/docs/reference/function-calls) |
| Functions, parameters, and closures | [Functions and closures](/docs/reference/functions-and-closures) |
| Strings, slices, and maps | [Strings](/docs/reference/strings), [Slices](/docs/reference/slices), and [Maps](/docs/reference/maps) |
| Type declarations and construction | [Enums](/docs/reference/enums) and [Structs and tuples](/docs/reference/structs-and-tuples) |
| Iteration and common operations | [For loops](/docs/reference/for-loops) and [Built-ins](/docs/reference/builtins) |
| Method and operator selection | [Overloads](/docs/reference/overloads) and [Template receiver methods](/docs/reference/template-receiver-method) |
| Embedded data, queries, and grammars | [Domain text literals](/docs/reference/domain-text-literals), [DQL](/docs/reference/dql), and [TPL](/docs/reference/tpl) |

For runnable introductions on this site, read [Functions](/docs/tutorials/functions), [Control flow](/docs/tutorials/control-flow), [Handle errors](/docs/tutorials/error-handling), [Types and values](/docs/reference/types), and [Go interoperability](/docs/interoperability/go).

This edition follows the source revision recorded with each page. It does not assign those materials to a stable XGo release. When reporting a discrepancy, include the page, source revision, toolchain version, and a small program that reproduces it.
