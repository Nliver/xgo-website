## 运行精简规范的语法检查器

源码检出目录包含用 [TPL](/zh-CN/docs/reference/tpl) 编写且可执行的精简规范语法。安装 XGo 后，在本文对应的源码检出目录根目录运行以下命令。

```sh
xgo go ./doc/spec/mini
cd cmd
xgo run ./chore/xgominispec -ast /path/to/hello.xgo
```

用要检查的 XGo 文件路径替换 `/path/to/hello.xgo`。如果文件包含 `echo "Hello, XGo"`，工具会输出 `==> Parsing` 和文件名，随后打印解析树。省略 `-ast` 时，工具会报告所解析的文件及发现的语法错误。输入可以是本地文件或目录。在路径末尾添加 `/...` 可递归扫描子目录。

此检查器将词法单元与 TPL 语法匹配。即使名称未定义，`echo missingName` 也能通过语法检查，因为名称解析和类型检查发生在编译阶段。在本文对应的源码版本中，编译器接受 C 风格的 `for` 循环，精简规范中的语法检查器则会拒绝它。使用 `xgo build` 检查完整程序。

## 记法

本规范使用扩展巴科斯范式（EBNF）的一个[变体](https://en.wikipedia.org/wiki/Wirth_syntax_notation)描述语法。

```text
Syntax      = { Production } .
Production  = production_name "=" [ Expression ] "." .
Expression  = Term { "|" Term } .
Term        = Factor { Factor } .
Factor      = production_name | token [ "…" token ] | Group | Option | Repetition .
Group       = "(" Expression ")" .
Option      = "[" Expression "]" .
Repetition  = "{" Expression "}" .
```
产生式是由项和以下运算符构成的表达式。运算符按优先级从低到高排列。

```text
|   alternation
()  grouping
[]  option (0 or 1 times)
{}  repetition (0 to n times)
```
小写的产生式名称表示词法单元（终结符），非终结符采用驼峰命名。词法单元用双引号或反引号括起。

`a … b` 表示从 a 到 b 的所有字符均可选用。规范中其他地方也会用水平省略号 `…` 简略表示未进一步定义的枚举或代码片段。XGo 的词法单元包括由三个点组成的 `...`，这里使用的单字符省略号 … 无法作为 XGo 的词法单元。

## 源代码表示

源代码是使用 [UTF-8](https://en.wikipedia.org/wiki/UTF-8) 编码的 Unicode 文本。编译器不会对文本做规范化。带重音的单一码位与通过组合重音符号和字母构造出的同一字符有区别，后者按两个码位处理。为简明起见，本文中的“字符”如无特别说明，均指源文本中的一个 Unicode 码位。

每个码位各自独立。例如，大写字母和小写字母是不同的字符。

实现限制。为兼容其他工具，编译器可以禁止在源文本中使用 NUL 字符（U+0000）。

实现限制。为兼容其他工具，如果以 UTF-8 编码的字节顺序标记（U+FEFF）位于源文本的第一个 Unicode 码位，编译器可以忽略它。编译器可以禁止字节顺序标记出现在源码中的其他位置。

### 字符

以下术语表示特定的 Unicode 字符类别。

```text
newline        = /* the Unicode code point U+000A */ .
unicode_char   = /* an arbitrary Unicode code point except newline */ .
unicode_letter = /* a Unicode code point categorized as "Letter" */ .
unicode_digit  = /* a Unicode code point categorized as "Number, decimal digit" */ .
```
[Unicode 标准 8.0](https://www.unicode.org/versions/Unicode8.0.0/) 第 4.5 节“General Category”定义了一组字符类别。Go 将属于 Letter 类别中的 Lu、Ll、Lt、Lm 或 Lo 的字符视为 Unicode 字母，将属于 Number 类别中 Nd 的字符视为 Unicode 数字。

### 字母和数字

下划线 `_`（U+005F）视为小写字母。

```text
letter        = unicode_letter | "_" .
decimal_digit = "0" … "9" .
binary_digit  = "0" | "1" .
octal_digit   = "0" … "7" .
hex_digit     = "0" … "9" | "A" … "F" | "a" … "f" .
```
## 词法元素

### 注释

注释用于记录程序说明，共有三种写法。

* _行注释_以字符序列 `//` 开始，到行尾结束。
* _行注释_以字符序列 `#` 开始，到行尾结束。
* _块注释_以字符序列 `/*` 开始，到其后首次出现的 `*/` 结束。

不含换行符的_块注释_等同于一个空格。其他注释等同于一个换行符。

```text
# this is a line comment
// this is another line comment
/* this is a general comment */
```
### 词法单元

词法单元构成 XGo 语言的词汇，包括_标识符_、_关键字_、_运算符_与_标点符号_以及_字面量_四类。空白字符包括空格（U+0020）、水平制表符（U+0009）、回车符（U+000D）和换行符（U+000A），仅在需要分隔原本会合并为一个词法单元的符号时起作用。此外，换行或文件结束可能触发[分号](#分号)插入。将输入切分为词法单元时，始终选用能构成有效词法单元的最长字符序列。

### 分号

形式语法以分号 `;` 作为一些产生式的结束符。XGo 程序可根据以下两条规则省略其中大部分分号。

* 对输入执行词法分析时，如果一行的最后一个词法单元属于以下任一项，就在其后立即向词法单元流插入一个分号。
  * [标识符](#标识符)。
  * [整数](#整数字面量)、[浮点数](#浮点数字面量)、[虚数](#虚数字面量)、[rune](#rune-字面量) 或[字符串](#字符串字面量)字面量。
  * [关键字](#关键字) `break`、`continue`、`fallthrough` 或 `return`。
  * 运算符或标点符号 `++`、`--`、`)`、`]` 或 `&#125;`。
* 为了允许将复杂语句写在一行内，可以省略右圆括号 `")"` 或右花括号 `"&#125;"` 前的分号。

为体现惯用写法，本文中的代码示例按上述规则省略分号。

标识符用于命名变量、类型等程序实体，由一个或多个字母和数字组成。标识符的首字符必须是字母。

### 整数字面量

整数字面量是表示[整数常量](#常量)的数字序列。可以使用前缀指定非十进制的基数。`0b` 和 `0B` 表示二进制，`0`、`0o` 和 `0O` 表示八进制，`0x` 和 `0X` 表示十六进制。单独的 `0` 视为十进制零。在十六进制字面量中，字母 `a` 至 `f` 和 `A` 至 `F` 表示数值 10 至 15。

为了便于阅读，可以在进制前缀之后或相邻数字之间添加下划线 `_`，它不会改变字面量的值。

```text
int_lit        = decimal_lit | binary_lit | octal_lit | hex_lit .
decimal_lit    = "0" | ( "1" … "9" ) [ [ "_" ] decimal_digits ] .
binary_lit     = "0" ( "b" | "B" ) [ "_" ] binary_digits .
octal_lit      = "0" [ "o" | "O" ] [ "_" ] octal_digits .
hex_lit        = "0" ( "x" | "X" ) [ "_" ] hex_digits .

decimal_digits = decimal_digit { [ "_" ] decimal_digit } .
binary_digits  = binary_digit { [ "_" ] binary_digit } .
octal_digits   = octal_digit { [ "_" ] octal_digit } .
hex_digits     = hex_digit { [ "_" ] hex_digit } .
```
```xgo
42
4_2
0600
0_600
0o600
0O600       // second character is capital letter 'O'
0xBadFace
0xBad_Face
0x_67_7a_2f_cc_40_c6
170141183460469231731687303715884105727
170_141183_460469_231731_687303_715884_105727

_42         // an identifier, not an integer literal
42_         // invalid: _ must separate successive digits
4__2        // invalid: only one _ at a time
0_xBadFace  // invalid: _ must separate successive digits
```
### 浮点数字面量

浮点数字面量以十进制或十六进制表示[浮点数常量](#常量)。

十进制浮点数字面量由整数部分（十进制数字）、小数点、小数部分（十进制数字）以及指数部分（`e` 或 `E`，后面是可选的符号和十进制数字）组成。整数部分和小数部分可以省略其中之一，小数点和指数部分也可以省略其中之一。指数 `exp` 表示将尾数（整数部分和小数部分）乘以 10 的 `exp` 次幂。

十六进制浮点数字面量由 `0x` 或 `0X` 前缀、整数部分（十六进制数字）、基数点、小数部分（十六进制数字）以及指数部分（`p` 或 `P`，后面是可选的符号和十进制数字）组成。整数部分和小数部分可以省略其中之一，也可省略基数点。指数部分必不可少。此语法符合 IEEE 754-2008 第 5.12.3 节。指数 `exp` 表示将尾数（整数部分和小数部分）乘以 2 的 `exp` 次幂。

为了便于阅读，可以在进制前缀之后或相邻数字之间添加下划线 `_`，它不会改变字面量的值。

```text
float_lit         = decimal_float_lit | hex_float_lit .

decimal_float_lit = decimal_digits "." [ decimal_digits ] [ decimal_exponent ] |
                    decimal_digits decimal_exponent |
                    "." decimal_digits [ decimal_exponent ] .
decimal_exponent  = ( "e" | "E" ) [ "+" | "-" ] decimal_digits .

hex_float_lit     = "0" ( "x" | "X" ) hex_mantissa hex_exponent .
hex_mantissa      = [ "_" ] hex_digits "." [ hex_digits ] |
                    [ "_" ] hex_digits |
                    "." hex_digits .
hex_exponent      = ( "p" | "P" ) [ "+" | "-" ] decimal_digits .
```
```xgo
0.
72.40
072.40       // == 72.40
2.71828
1.e+0
6.67428e-11
1E6
.25
.12345E+5
1_5.         // == 15.0
0.15e+0_2    // == 15.0

0x1p-2       // == 0.25
0x2.p10      // == 2048.0
0x1.Fp+0     // == 1.9375
0X.8p-0      // == 0.5
0X_1FFFP-16  // == 0.1249847412109375

0x15e-2      // == 0x15e - 2 (integer subtraction)

0x.p1        // invalid: mantissa has no digits
1p-2         // invalid: p exponent requires hexadecimal mantissa
0x1.5e-2     // invalid: hexadecimal mantissa requires p exponent
1_.5         // invalid: _ must separate successive digits
1._5         // invalid: _ must separate successive digits
1.5_e1       // invalid: _ must separate successive digits
1.5e_1       // invalid: _ must separate successive digits
1.5e1_       // invalid: _ must separate successive digits
```
### 有理数字面量

XGo 中的有理数字面量有两种形式。

* **有理数整数形式**写作整数加后缀 `r`。
* **分数形式**依次写上分子、除法运算符 `/`、分母和后缀 `r`。

```text
rational_lit   = rational_int | rational_frac .
rational_int   = int_lit "r" .
rational_frac  = int_lit "/" int_lit "r" .
```
下面是几种写法。

```sh
1r       # Rational integer 1
2/3r     # Fraction 2/3
```
### 虚数字面量

虚数字面量表示[复数常量](#常量)的虚部，由一个[整数](#整数字面量)或[浮点数](#浮点数字面量)字面量加小写字母 `i` 组成。它的值等于对应整数或浮点数字面量的值乘以虚数单位 `i`。

```text
imaginary_lit = (decimal_digits | int_lit | float_lit) "i" .
```
为保持向后兼容，虚数字面量的整数部分若只包含十进制数字和可选的下划线，即使以 `0` 开头，也应视为十进制整数。

```xgo
0i
0123i         // == 123i for backward-compatibility
0o123i        // == 0o123 * 1i == 83i
0xabci        // == 0xabc * 1i == 2748i
0.i
2.71828i
1.e+0i
6.67428e-11i
1E6i
.25i
.12345E+5i
0x1p-2i       // == 0x1p-2 * 1i == 0.25i
```

### rune 字面量

rune 字面量表示 [rune 常量](#常量)，即标识 Unicode 码位的整数。它由单引号括起的一个或多个字符组成，例如 `'x'` 或 `'\n'`。
引号中可以包含换行符和未转义的单引号之外的任意字符。由单引号括起的单个字符直接表示该字符的 Unicode 值，以反斜杠开头的多字符序列可以用多种格式编码该值。

最简单的形式是直接表示引号中的一个字符。XGo 源文本是 UTF-8 编码的 Unicode 字符，因此一个整数值可能由多字节的 UTF-8 编码表示。例如，字面量 `'a'` 由单个字节表示字母 a，其码位为 `U+0061`、值为 `0x61`。`'ä'` 由两个字节（`0xc3`、`0xa4`）表示带分音符的 a，其码位为 `U+00E4`、值为 `0xe4`。

可以使用反斜杠转义序列，将任意值编码成 ASCII 文本。用数值常量表示整数值时有四种写法。`\x` 后跟恰好两个十六进制数字，`\u` 后跟恰好四个十六进制数字，`\U` 后跟恰好八个十六进制数字，单个反斜杠 `\` 后跟恰好三个八进制数字。每种写法的字面量值都等于这些数字在相应进制下表示的值。

这些写法都得到整数，但合法取值范围不同。八进制转义必须表示 0 至 255 之间的值，含端点。双位十六进制转义自然满足这一条件。`\u` 和 `\U` 转义表示 Unicode 码位，部分值非法，尤其是超过 `0x10FFFF` 的值和代理码位。

反斜杠之后的某些单字符转义表示特殊值。

```text
\a   U+0007 alert or bell
\b   U+0008 backspace
\f   U+000C form feed
\n   U+000A line feed or newline
\r   U+000D carriage return
\t   U+0009 horizontal tab
\v   U+000B vertical tab
\\   U+005C backslash
\'   U+0027 single quote  (valid escape only within rune literals)
\"   U+0022 double quote  (valid escape only within string literals)
```
rune 字面量中的反斜杠之后不能出现无法识别的字符。

```text
rune_lit         = "'" ( unicode_value | byte_value ) "'" .
unicode_value    = unicode_char | little_u_value | big_u_value | escaped_char .
byte_value       = octal_byte_value | hex_byte_value .
octal_byte_value = `\` octal_digit octal_digit octal_digit .
hex_byte_value   = `\` "x" hex_digit hex_digit .
little_u_value   = `\` "u" hex_digit hex_digit hex_digit hex_digit .
big_u_value      = `\` "U" hex_digit hex_digit hex_digit hex_digit
                           hex_digit hex_digit hex_digit hex_digit .
escaped_char     = `\` ( "a" | "b" | "f" | "n" | "r" | "t" | "v" | `\` | "'" | `"` ) .
```
```xgo
'a'
'ä'
'本'
'\t'
'\000'
'\007'
'\377'
'\x07'
'\xff'
'\u12e4'
'\U00101234'
'\''         // rune literal containing single quote character
'aa'         // illegal: too many characters
'\k'         // illegal: k is not recognized after a backslash
'\xa'        // illegal: too few hexadecimal digits
'\0'         // illegal: too few octal digits
'\400'       // illegal: octal value over 255
'\uDFFF'     // illegal: surrogate half
'\U00110000' // illegal: invalid Unicode code point
```
### 字符串字面量

字符串字面量表示一系列字符拼接得到的[字符串常量](#常量)，有原始字符串字面量和解释型字符串字面量两种形式。

原始字符串字面量是反引号之间的字符序列，例如 \`foo\`。引号中可以包含反引号之外的任意字符。其值由引号之间未进行转义解释的字符组成，字符隐式采用 UTF-8 编码。反斜杠没有特殊含义，字符串可以包含换行符。原始字符串字面量中的回车符（`'\r'`）会从字面量值中去除。

解释型字符串字面量是双引号之间的字符序列，例如 `"bar"`。引号中可以包含换行符和未转义的双引号之外的任意字符。引号之间的文本构成字面量的值。反斜杠转义的解释方式和限制与 [rune 字面量](#rune-字面量)一致，区别在于此处 `\'` 非法、`\"` 合法。
三位八进制转义（`\nnn`）和两位十六进制转义（`\xnn`）各表示结果字符串中的一个字节。其他转义表示单个字符的 UTF-8 编码，可能占多个字节。因此，字符串字面量中的 `\377` 和 `\xFF` 表示单个字节 `0xFF`（255），`ÿ`、`\u00FF`、`\U000000FF` 和 `\xc3\xbf` 则表示字符 `U+00FF` 的 UTF-8 编码，即 `0xc3` 和 `0xbf` 两个字节。

```text
string_lit             = raw_string_lit | interpreted_string_lit .
raw_string_lit         = "`" { unicode_char | newline } "`" .
interpreted_string_lit = `"` { unicode_value | byte_value } `"` .
```
```xgo
`abc`                // same as "abc"
`\n
\n`                  // same as "\\n\n\\n"
"\n"
"\""                 // same as `"`
"Hello, world!\n"
"日本語"
"\u65e5本\U00008a9e"
"\xff\u00FF"
"\uD800"             // illegal: surrogate half
"\U00110000"         // illegal: invalid Unicode code point
```
以下示例都表示相同的字符串。

```xgo
"日本語"                                 // UTF-8 input text
`日本語`                                 // UTF-8 input text as a raw literal
"\u65e5\u672c\u8a9e"                    // the explicit Unicode code points
"\U000065e5\U0000672c\U00008a9e"        // the explicit Unicode code points
"\xe6\x97\xa5\xe6\x9c\xac\xe8\xaa\x9e"  // the explicit UTF-8 bytes
```
如果源代码用两个码位表示同一个字符，例如由重音符号和字母组成的组合形式，那么在 rune 字面量中使用它会出错，因为 rune 字面量要求单一码位。在字符串字面量里使用它时，两个码位都会保留。

## 常量

常量包括_布尔常量_、_rune 常量_、_整数常量_、_浮点数常量_、_复数常量_和_字符串常量_。rune、整数、浮点数和复数常量统称为_数值常量_。

常量值可以用以下形式表示。[rune](#rune-字面量)、[整数](#整数字面量)、[浮点数](#浮点数字面量)、[虚数](#虚数字面量)、[布尔值](#布尔字面量)或[字符串](#字符串字面量)字面量、表示常量的标识符、[常量表达式](#常量表达式)、结果为常量的[转换](#类型转换)，以及某些内置函数的调用结果。此类调用包括对常量实参调用 `min` 或 `max`、对特定值调用 `unsafe.Sizeof`、对[某些表达式](#长度和容量)调用 `cap` 或 `len`、对复数常量调用 `real` 或 `imag`，以及对数值常量调用 `complex`。预声明常量 `true` 和 `false` 表示布尔真值。预声明标识符 `iota` 表示整数常量。

有些字面量不构成常量。参见以下示例。

```sh
nil
1r
2/3r
```
通常，复数常量是[常量表达式](#常量表达式)的一种形式。相关规则见该节。

数值常量精确表示任意精度的值，且不会溢出。因此，没有常量表示 IEEE-754 的负零、无穷大和非数值。

常量可以有[类型](#类型)，也可以是_无类型_的。字面量常量（包括 `true`、`false` 和 `iota`），以及只包含无类型常量操作数的某些[常量表达式](#常量表达式)，都没有类型。

常量可以通过[常量声明](#常量声明)或[转换](#类型转换)显式获得类型。常量用于[变量声明](#变量声明)、[赋值语句](#赋值语句)或作为[表达式](#表达式)的操作数时，也可能隐式获得类型。如果常量值无法用相应类型的值[表示](#可表示性)，就会报错。

无类型常量有一个_默认类型_。在要求使用有类型值的上下文中，常量隐式转换为默认类型，例如在未显式写出类型的[短变量声明](#短变量声明) `i := 0` 中。布尔、rune、整数、浮点数、复数、字符串常量的默认类型依次是 `bool`、`rune`、`int`、`float64`、`complex128` 和 `string`。


## 变量

变量是存放一个值的存储位置。变量允许保存哪些值由其[类型](#类型)决定。

[变量声明](#变量声明)会为具名变量保留存储空间。对函数的参数和结果，[函数声明](#函数声明)或[函数字面量](#函数字面量)的签名也有这个作用。调用内置函数 [new](#分配)，或取[复合字面量](/zh-CN/docs/reference/full-specification#复合字面量)的地址，会在运行时为变量分配存储空间。通过[指针间接引用](#地址运算符)访问这种匿名变量，指针解引用可以是隐式的。

[数组](#数组类型)、[切片](#切片类型)和[类](#类)等_结构化_变量包含可单独[取地址](#地址运算符)的元素和字段。每个这样的元素都可作为变量使用。

变量的_静态类型_（简称_类型_）是声明中的类型、调用 `new` 或复合字面量时给出的类型，或类变量的元素类型。接口类型的变量还有单独的_动态类型_，即在运行时赋给变量的值的非接口类型。预声明标识符 `nil` 没有类型。动态类型可能随执行而变化，但接口变量中保存的值始终可以[赋给](#可赋值性)变量的静态类型。

```xgo
var x any  // x is nil and has static type any
var v *T   // v has value nil, static type *T
x = 42     // x has value 42 and dynamic type int
x = v      // x has value (*T)(nil) and dynamic type *T
```
在[表达式](#表达式)中引用变量，可以读取最近一次[赋予](#赋值语句)该变量的值。如果变量从未被赋值，它的值是对应类型的[零值](#零值-1)。


## 类型

类型决定一组值，以及这些值特有的操作和方法。可以用_类型名_指代类型。也可以使用类型字面量，以现有类型构造新类型。

```text
Type      = TypeName [ TypeArgs ] | TypeLit | "(" Type ")" .
TypeName  = identifier | QualifiedIdent .
TypeArgs  = "[" TypeList [ "," ] "]" .
TypeList  = Type { "," Type } .
TypeLit   = ArrayType | TupleType | PointerType | FunctionType | InterfaceType |
            SliceType | MapType . // TODO: check this
```
语言[预声明](#预声明标识符)了一些类型名，其他类型名通过[类型声明](#类型声明)引入。数组、元组、指针、函数、接口、切片和映射等_复合类型_可用类型字面量构造。

预声明类型和定义类型统称为_命名类型_。如果别名声明中给出的类型是命名类型，则该别名也指代命名类型。

### 布尔类型

_布尔类型_表示由预声明常量 `true` 和 `false` 指定的布尔真值集合。预声明的布尔类型是 `bool`，它是定义类型。

```xgo
bool
```
### 数值类型

_整数_、_浮点数_、_有理数_和_复数_类型各自表示对应的数值集合，统称为_数值类型_。与硬件架构无关的预声明数值类型如下。

```xgo
uint8       // the set of all unsigned  8-bit integers (0 to 255)
uint16      // the set of all unsigned 16-bit integers (0 to 65535)
uint32      // the set of all unsigned 32-bit integers (0 to 4294967295)
uint64      // the set of all unsigned 64-bit integers (0 to 18446744073709551615)

int8        // the set of all signed  8-bit integers (-128 to 127)
int16       // the set of all signed 16-bit integers (-32768 to 32767)
int32       // the set of all signed 32-bit integers (-2147483648 to 2147483647)
int64       // the set of all signed 64-bit integers (-9223372036854775808 to 9223372036854775807)

float32     // the set of all IEEE-754 32-bit floating-point numbers
float64     // the set of all IEEE-754 64-bit floating-point numbers

complex64   // the set of all complex numbers with float32 real and imaginary parts
complex128  // the set of all complex numbers with float64 real and imaginary parts

byte        // alias for uint8
rune        // alias for int32
```
一个 _n_ 位整数的值占 n 位，采用[二进制补码](https://en.wikipedia.org/wiki/Two's_complement)表示。

以下预声明整数类型的大小由具体实现决定。

```xgo
uint     // either 32 or 64 bits
int      // same size as uint
uintptr  // an unsigned integer large enough to store the uninterpreted bits of a pointer value
```
为避免可移植性问题，所有数值类型均为互不相同的定义类型，`byte` 和 `rune` 除外。`byte` 是 `uint8` 的[别名](#别名声明)，`rune` 是 `int32` 的别名。在表达式或赋值中混用不同的数值类型时，必须显式转换。例如，`int32` 和 `int` 在某种架构上即使大小相同，也属于不同的类型。

### 字符串类型

_字符串类型_表示字符串值的集合。一个字符串值由零个或多个字节组成。字符串的长度是字节数，始终为非负数。字符串不可变，创建后无法修改其中的内容。预声明字符串类型为 `string`，它是定义类型。

```xgo
string
```
用内置函数 [len](#长度和容量) 获取字符串 `s` 的长度。如果字符串是常量，长度也是编译期常量。用 `0` 到 `len(s)-1` 的整数索引访问字符串的字节。这些元素不能取地址。例如，若 `s[i]` 是字符串的第 i 个字节，则 `&s[i]` 无效。


### 数组类型

数组是一组带索引的元素序列，所有元素具有同一个类型，称为元素类型。元素个数称为数组的长度，始终为非负数。

```text
ArrayType   = "[" ArrayLength "]" ElementType .
ArrayLength = Expression .
ElementType = Type .
```
长度是数组类型的一部分，必须求值为可用 `int` 类型[表示](#可表示性)的非负[常量](#常量)。可以用内置函数 [len](#长度和容量) 查询数组 `a` 的长度，并用 `0` 到 `len(a)-1` 的整数索引访问元素。数组类型本身都是一维的，可以通过组合构造多维类型。

```xgo
[32]byte
[2*N](x int32, y int32)
[1000]*float64
[3][5]int
[2][2][2]float64  // same as [2]([2]([2]float64))
```
数组类型 `T` 不得包含类型为 `T` 的元素，也不得包含直接或间接以 `T` 为组成部分的元素类型，前提是这些包含路径上的类型均为数组或元组。

```xgo
// invalid array types
type (
	T1 [10]T1                 // element type of T1 is T1
	T2 [10](f T2)             // T2 contains T2 as component of a tuple
	T3 [10]T4                 // T3 contains T3 as component of a tuple in T4
	T4 (f [10]T3)             // T4 contains T4 as component of array T3 in a tuple
)

// valid array types
type (
	T5 [10]*T5                // T5 contains T5 as component of a pointer
	T6 [10]func() T6          // T6 contains T6 as component of a function type
	T7 [10](f []T7)           // T7 contains T7 as component of a slice in a tuple
)
```
### 指针类型

_指针_类型表示指向某一给定类型的所有[变量](#变量)的指针集合。所指变量的类型称为指针的基类型。未初始化的指针值为 `nil`。

```text
PointerType = "*" BaseType .
BaseType    = Type .
```
```xgo
*Point
*[4]int
```
### 切片类型

_切片_是对_底层数组_中连续片段的描述，可以用索引访问该数组中的一段元素。切片类型表示其元素类型所构成的数组的所有切片。元素个数称为切片长度，始终为非负数。未初始化的切片值为 `nil`。

```text
SliceType = "[" "]" ElementType .
```
用内置函数 [len](#长度和容量) 查询切片 `s` 的长度。切片的长度可以在执行期间变化，数组的长度固定。可以用 `0` 到 `len(s)-1` 的整数索引访问切片元素。给定元素在切片中的索引可以小于它在底层数组中的索引。

切片初始化后始终关联一个存储其元素的底层数组。因此，切片和它的底层数组及同一数组的其他切片共享存储。不同的数组各自拥有独立的存储空间。

切片的底层数组可以延伸到切片的末尾之后。容量等于切片的长度，加上其末尾之后的数组元素数。基于原切片再次切片时，新切片的长度最大可达这个容量。用内置函数 `cap(a)` 查询切片 `a` 的容量。

用内置函数 [make](#长度和容量) 可以创建元素类型为 `T` 的已初始化切片。`make` 接收切片类型、长度以及可选的容量。用 `make` 创建切片总会分配一个新的隐藏数组，返回的切片引用该数组。执行下列表达式

```xgo
make([]T, length, capacity)
```
得到的切片等同于先分配数组，再从中截取的切片。因此以下两个表达式等价。

```text
make([]int, 50, 100)
new([100]int)[0:50]
```
与数组一样，切片本身都是一维的，可以通过组合构造更高维的对象。在以数组为元素的数组中，内部数组的长度由类型决定，因此始终相等。对于切片的切片或切片的数组，内部切片的长度可以动态变化，且各内部切片必须分别初始化。

### 元组类型

_元组_类型是将多个值组合在一起的轻量数据结构。元组类型是匿名结构体的语法糖，字段按顺序命名为 `X_0`、`X_1` 等。元组中的具名字段是编译期别名，便于阅读，运行时映射到对应顺序的字段。

```text
TupleType = Parameters .
```
元组类型用圆括号包裹、逗号分隔的类型列表表示，可以为元素指定名称。

```xgo
// Empty tuple (equivalent to struct{})
()

// Anonymous tuples (elements accessed by ordinal: .0, .1, .2)
(int, string)
(int, string, bool)

// Named tuples (compile-time names for readability, runtime uses ordinal fields)
type Point (x int, y int)
type Person (name string, age int)

// Type shorthand syntax (same as: x int, y int, z int)
type Point3D (x, y, z int)
```
**单元素退化**。单元素写法 `(T)` 或 `(value T)` 退化为类型 `T` 本身。

#### 构造元组

元组使用**函数调用风格的语法**构造。

```xgo
// Positional construction
p := Point(10, 20)
result := (42, "success", true)

// Keyword argument construction (using = for clarity)
p := Point(x = 10, y = 20)
person := Person(name = "Alice", age = 30)
```
#### 字段访问

可以用以下两种方式访问元组的字段。
- **具名字段**，例如使用声明的名称 `p.x` 和 `p.y`。
- **顺序编号**，例如使用数字简写 `p.0` 和 `p.1`。

```xgo
type Point (x int, y int)
p := Point(10, 20)

echo p.x      // 10 (using compile-time name)
echo p.0      // 10 (using ordinal index, equivalent to p.x)
echo p.y      // 20
echo p.1      // 20
```
#### 元组类型标识

如果两个元组的元素数量相同且对应元素的类型完全相同，则它们是相同的元组类型。元素名称不影响类型标识。

```xgo
type Point (x int, y int)
type Coord (a int, b int)

// Point and Coord have identical underlying types (both map to struct{ X_0 int; X_1 int })
// but are different named types
```
#### 复合类型中的元组

元组可用作数组、切片、映射和通道的元素类型。

```xgo
// Tuple as map value type
var cache map[string](int, bool)

// Tuple as slice element type
var pairs [](string, int)

// Tuple as channel element type
var ch chan (int, error)
```
#### 递归类型限制

元组类型 `T` 不得包含类型为 `T` 的元素，也不得包含直接或间接以 `T` 为组成部分的元素类型，前提是这些包含路径上的类型均为数组或元组。

```xgo
// invalid tuple types
type (
	T1 (T1, int)              // T1 contains an element of T1
	T2 ([10]T2, string)       // T2 contains T2 as component of an array
)

// valid tuple types
type (
	T3 (*T3, int)             // T3 contains T3 as component of a pointer
	T4 (func() T4, string)    // T4 contains T4 as component of a function type
	T5 ([]T5, int)            // T5 contains T5 as component of a slice
)
```
### 映射类型

_映射_是一组无序元素。这些元素拥有同一个类型，称为元素类型，并通过一组唯一的_键_索引。键的类型称为键类型。未初始化的映射值为 `nil`。

```text
MapType     = "map" "[" KeyType "]" ElementType .
KeyType     = Type .
```
比较运算符 `==` 和 `!=` 必须对键类型的操作数完整定义，因此键的类型不能是函数、映射或切片。如果键的类型是接口，这两个运算符还必须对键的动态值有定义，否则会引发运行时 panic。

```xgo
map[string]int
map[*T](x float64, y float64)
map[string]any
```
映射的长度是元素的数量。用内置函数 [len](#长度和容量) 查询映射 `m` 的长度，其值可随程序执行而变化。运行时可用[赋值](#赋值语句)增加元素，用索引表达式读取元素，用内置函数 [delete](#删除映射元素) 或 [clear](#clear) 删除元素。

内置函数 [make](#长度和容量) 接收映射类型和可选的容量提示，创建一个新的空映射。

```xgo
make(map[string]int)
make(map[string]int, 100)
```
初始容量不限制映射的大小。映射可以增长以容纳所保存的元素。值为 `nil` 的映射相当于空映射，但无法向其中添加元素。

### 函数类型

_函数_类型表示拥有相同参数和结果类型的所有函数的集合。未初始化的函数类型变量的值为 `nil`。

```text
FunctionType   = "func" Signature .
Signature      = Parameters [ Result ] .
Result         = Parameters | Type .
Parameters     = "(" [ ParameterList [ "," ] ] ")" .
ParameterList  = ParameterDecl { "," ParameterDecl } .
ParameterDecl  = [ IdentifierList ] [ "..." ] Type .
```
参数或结果列表中的名称（`IdentifierList`）必须全部提供或全部省略。提供名称时，每个名称表示一个给定类型的参数或结果，且签名中所有非[空白](#空白标识符)名称必须[唯一](#标识符的唯一性)。省略名称时，每个类型表示该类型的一个参数或结果。参数列表和结果列表总是用圆括号括起。如果恰好只有一个没有名称的结果，可以直接写出类型并省略圆括号。

函数签名的最后一个输入参数可以在类型前加 `...`。包含这类参数的函数称为_可变参数函数_，调用时可为该参数提供零个或多个实参。

```xgo
func()
func(x int) int
func(a, _ int, z float32) bool
func(a, b int, z float32) (bool)
func(prefix string, values ...int)
func(a, b int, z float64, opt ...any) (success bool)
func(int, int, float64) (float64, *[]int)
func(n int) func(p *T)
```
### 接口类型

接口类型指定一个[方法集](#方法集)，称为该类型的_接口_。只要某类型的方法集包含接口要求的全部方法，接口类型变量就能保存该类型的值，这时称该类型_实现了接口_。未初始化的接口类型变量的值为 `nil`。

```text
InterfaceType      = "interface" "{" { ( MethodSpec | InterfaceTypeName ) ";" } "}" .
MethodSpec         = MethodName Signature .
MethodName         = identifier .
InterfaceTypeName  = TypeName .
```
接口类型可以通过方法规范_显式_指定方法，也可以通过其他接口的类型名_嵌入_那些接口的方法。

```xgo
// A simple File interface.
interface {
	Read([]byte) (int, error)
	Write([]byte) (int, error)
	Close() error
}
```
显式指定的方法名称必须[唯一](#标识符的唯一性)，并且不能使用[空白标识符](#空白标识符)。

```xgo
interface {
	String() string
	String() string  // illegal: String not unique
	_(x int)         // illegal: method must have non-blank name
}
```
多个类型可以实现同一个接口。例如，如果两个类型 `S1` 和 `S2` 都拥有以下方法集

```xgo
func Read(p []byte) (n int, err error)
func Write(p []byte) (n int, err error)
func Close() error
```
其中 `T` 代表 `S1` 或 `S2`，则二者都实现了 `File` 接口，无论它们分别拥有或共有其他哪些方法。

如果某接口要求的方法是一个类型的方法集的子集，该类型就实现了这个接口。因此，一个类型可以实现多个不同的接口。例如，所有类型都实现_空接口_。

```xgo
interface{}
```
接下来考虑以下接口规范，它在[类型声明](#类型声明)中定义名为 `Locker` 的接口。

```xgo
type Locker interface {
	Lock()
	Unlock()
}
```
若 `S1` 和 `S2` 还实现以下方法

```xgo
func Lock() { … }
func Unlock() { … }
```
则二者也实现了 `Locker` 接口。

接口 `T` 可以用接口类型名 `E` 代替方法规范。类型名可以带限定符。称这种写法为将接口 `E` _嵌入_ `T`。`T` 的方法集由显式声明的方法与所有嵌入接口的方法集合并而成。

```xgo
type Reader interface {
	Read(p []byte) (n int, err error)
	Close() error
}

type Writer interface {
	Write(p []byte) (n int, err error)
	Close() error
}

// ReadWriter's methods are Read, Write, and Close.
type ReadWriter interface {
	Reader  // includes methods of Reader in ReadWriter's method set
	Writer  // includes methods of Writer in ReadWriter's method set
}
```
多个方法集的并集只保留一次各方法集中的每个方法，包含导出和未导出的方法。[同名](#类型标识)方法的签名必须[相同](#类型标识)。

```xgo
type ReadCloser interface {
	Reader   // includes methods of Reader in ReadCloser's method set
	Close()  // illegal: signatures of Reader.Close and Close are different
}
```
接口类型 `T` 不能嵌入自身，也不能嵌入直接或间接嵌入了 `T` 的接口类型。

```xgo
// illegal: Bad cannot embed itself
type Bad interface {
	Bad
}

// illegal: Bad1 cannot embed itself using Bad2
type Bad1 interface {
	Bad2
}
type Bad2 interface {
	Bad1
}
```
#### 内置接口

XGo 预声明了以下接口。

```xgo
any    // alias for interface{}, the empty interface
error  // interface for error handling
```
##### `any` 接口

预声明类型 `any` 是空接口 `interface&#123;&#125;` 的别名，表示所有类型的集合，可用于处理任意类型的值。

```xgo
var x any  // x is nil and has static type any
x = 42     // x has value 42 and dynamic type int
x = "hello" // x has value "hello" and dynamic type string
```
##### `error` 接口

预声明类型 `error` 的定义如下。

```xgo
type error interface {
	Error() string
}
```
`error` 是表示出错情况的惯用接口，用 `nil` 表示未发生错误。例如，从文件读取数据的函数可以这样定义。

```xgo
func Read(f *File, b []byte) (n int, err error)
```
任何实现了返回字符串的 `Error()` 方法的类型都满足 `error` 接口。

### 底层类型

每个类型 `T` 都有一个_底层类型_。如果 `T` 是预声明的布尔、数值、字符串类型之一，或由类型字面量指定，则其底层类型为 `T` 本身。否则，`T` 的底层类型是其声明所引用类型的底层类型。

```xgo
type (
	A1 = string
	A2 = A1
)

type (
	B1 string
	B2 B1
	B3 []B1
	B4 B3
)
```
`string`、`A1`、`A2`、`B1` 和 `B2` 的底层类型是 `string`。`[]B1`、`B3` 和 `B4` 的底层类型是 `[]B1`。

### 类型标识

两个类型要么_相同_，要么_不同_。

一个[命名类型](#类型)始终与任何其他类型不同。对于其余情况，如果两个类型的[底层类型](#底层类型)字面量在结构上等价，也就是字面量结构相同且对应组成部分的类型相同，则这两个类型相同。具体规则如下。

* 两个数组的元素类型相同、数组长度相同，则它们的类型相同。
* 两个切片的元素类型相同，则它们的类型相同。
* 两个结构体的字段顺序相同、对应的字段名称相同、类型相同且标签相同，则它们的类型相同。来自不同包的[未导出](#导出标识符)字段名称始终不同。
* 两个指针的基类型相同，则它们的类型相同。
* 两个函数的参数数量相同、结果数量相同、对应的参数及结果类型相同，且二者均为可变参数函数或均为固定参数函数，则它们的类型相同。参数和结果的名称可以不同。
* 如果两个接口定义的类型集相同，则它们的类型相同。
* 两个映射的键类型和元素类型均相同，则它们的类型相同。

给定以下声明

```xgo
type (
	A0 = []string
	A1 = A0
	A2 = struct{ a, b int }
	A3 = int
	A4 = func(A3, float64) *A0
	A5 = func(x int, _ float64) *[]string

	B0 A0
	B1 []string
	B2 struct{ a, b int }
	B3 struct{ a, c int }
	B4 func(int, float64) *B0
	B5 func(x int, y float64) *A1

	C0 = B0
)
```
以下各行中的两个类型相同。

```xgo
A0, A1, and []string
A2 and struct{ a, b int }
A3 and int
A4, func(int, float64) *[]string, and A5

B0 and C0
[]int and []int
struct{ a, b *B5 } and struct{ a, b *B5 }
func(x int, y float64) *[]string, func(int, float64) (result *[]string), and A5
```
`B0` 和 `B1` 是不同的类型，因为它们是不同[类型定义](#类型定义)创建的新类型。`func(int, float64) *B0` 和 `func(x int, y float64) *[]string` 也是不同的类型，因为 `B0` 不同于 `[]string`。

### 可赋值性

如果满足以下任一条件，类型为 `V` 的值 `x` 可以_赋给_类型为 `T` 的[变量](#变量)，简称“`x` 可赋给 `T`”。

* `V` 和 `T` 相同。
* `V` 和 `T` 的[底层类型](#底层类型)相同，二者都不是类型参数，且至少一方不是[命名类型](#类型)。
* `T` 是接口类型，而 `x` [实现了](#接口类型) `T`。
* `x` 是预声明标识符 `nil`，而 `T` 是指针、函数、切片、映射或接口类型。
* `x` 是无类型[常量](#常量)，且可用类型 `T` 的值[表示](#可表示性)。

### 可表示性

满足以下任一条件时，[常量](#常量) `x` 可用类型 `T` 的值_表示_。

* `x` 属于 `T` [决定](#类型)的值集合。
* `T` 是浮点数类型，且 `x` 能够舍入到 `T` 的精度而不溢出。舍入遵循 IEEE 754 的舍入到偶数规则，并将 IEEE 负零简化为无符号零。常量值不会产生 IEEE 负零、NaN 或无穷大。
* `T` 是复数类型，且 `x` 的[实部和虚部](#操作复数) `real(x)` 和 `imag(x)` 均可用 `T` 的分量类型（`float32` 或 `float64`）的值表示。

```xgo
x                   T           x is representable by a value of T because

'a'                 byte        97 is in the set of byte values
97                  rune        rune is an alias for int32, and 97 is in the set of 32-bit integers
"foo"               string      "foo" is in the set of string values
1024                int16       1024 is in the set of 16-bit integers
42.0                byte        42 is in the set of unsigned 8-bit integers
1e10                uint64      10000000000 is in the set of unsigned 64-bit integers
2.718281828459045   float32     2.718281828459045 rounds to 2.7182817 which is in the set of float32 values
-1e-1000            float64     -1e-1000 rounds to IEEE -0.0 which is further simplified to 0.0
0i                  int         0 is an integer value
(42 + 0i)           float32     42.0 (with zero imaginary part) is in the set of float32 values
```
```xgo
x                   T           x is not representable by a value of T because

0                   bool        0 is not in the set of boolean values
'a'                 string      'a' is a rune, it is not in the set of string values
1024                byte        1024 is not in the set of unsigned 8-bit integers
-1                  uint16      -1 is not in the set of unsigned 16-bit integers
1.1                 int         1.1 is not an integer value
42i                 float32     (0 + 42i) is not in the set of float32 values
1e1000              float64     1e1000 overflows to IEEE +Inf after rounding
```
### 方法集

类型的_方法集_决定了在该类型[操作数](#操作数)上可以[调用](#命令与调用)的方法。每个类型都对应一个方法集，可以为空。

* [定义类型](#类型定义) `T` 的方法集包括所有声明接收者类型为 `T` 的方法。
* 指向定义类型 `T` 的指针的方法集包括所有声明接收者类型为 `*T` 或 `T` 的方法，前提是 `T` 既不是指针也不是接口。
* [接口类型](#接口类型)的方法集是该接口[类型集](#接口类型)中所有类型的方法集的交集。所得方法集通常就是接口内声明的方法。

结构体及指向结构体的指针若含嵌入字段，还适用结构体类型一节中的规则。其余类型的方法集为空。

方法集中每个方法的名称都必须[唯一](#标识符的唯一性)，且不能是[空白标识符](#空白标识符)。


## 表达式

表达式通过对操作数应用运算符和函数计算一个值。

### 操作数

操作数表示表达式中的基本值，可以是字面量、代表[常量](#常量声明)、[变量](#变量声明)或[函数](#函数声明)的非[空白](#空白标识符)标识符（可带[限定符](#限定标识符)），或用圆括号括起的表达式。

```text
Operand     = Literal | OperandName [ TypeArgs ] .
Literal     = BasicLit | FunctionLit | TupleLit .
BasicLit    = int_lit | float_lit | imaginary_lit | rune_lit | string_lit .
OperandName = identifier | QualifiedIdent .
```
[空白标识符](#空白标识符)作为操作数时，只能出现在[赋值语句](#赋值语句)的左侧。

### 限定标识符

_限定标识符_是以包名为前缀的标识符。包名和标识符都不能是[空白标识符](#空白标识符)。

```text
QualifiedIdent = PackageName "." identifier .
```
限定标识符用于访问另一个包里的标识符，必须先[导入](#导入声明)该包。所访问的标识符必须是[导出](#导出标识符)的，且在该包的[包块](#代码块)中声明。

```xgo
math.Sin // denotes the Sin function in package math
```
### 元组字面量

元组字面量用函数调用风格的语法构造元组值。匿名元组和命名元组都可用圆括号包住逗号分隔的表达式来创建。

```text
TupleLit = "(" [ ExpressionList [ "," ] ] ")" .
```
#### 匿名元组字面量

匿名元组字面量用于创建匿名元组类型的值。

```xgo
result := (42, "success", true)        // creates a (int, string, bool)
pair := (10, 20)                       // creates a (int, int)
empty := ()                            // creates an empty tuple ()
```
#### 构造具名元组

使用函数调用风格的语法实例化命名元组类型。

**位置实参**

```xgo
type Point (x int, y int)
p := Point(10, 20)              // positional construction

type Person (name string, age int)
alice := Person("Alice", 30)    // positional construction
```
**关键字实参**

关键字实参使用 `=` 为字段赋值，有助于阅读包含较多字段的元组初始化。

```xgo
p := Point(x = 10, y = 20)              // keyword argument construction
person := Person(name = "Bob", age = 25) // keyword argument construction
```
可以混用位置实参和关键字实参，但位置实参必须全部在前。

```xgo
// This is valid
p := Point(10, y = 20)

// This is invalid
// p := Point(x = 10, 20)  // error: positional arg after keyword arg
```
#### 零值

调用元组类型时若不提供实参，会返回该类型的零值。

```xgo
type Point (x int, y int)
zero := Point()   // equivalent to Point(0, 0)
```
#### 类型推断

如果上下文提供了足够的信息，元组字面量的类型会由上下文推断。

```xgo
func process(p (int, string)) {
	// ...
}

process((42, "hello"))  // tuple literal type inferred as (int, string)
```
#### 复合类型中的元组字面量

元组字面量可用作切片、数组和映射的元素。

```xgo
pairs := [](string, int){
	("a", 1),
	("b", 2),
	("c", 3),
}

// In a map
cache := map[string](int, bool){
	"key1": (100, true),
	"key2": (200, false),
}
```
### 函数字面量

函数字面量表示匿名[函数](#函数声明)。

```text
FunctionLit                 = [ AnonymousParameters ] "=>" AnonymousFunctionBody .
AnonymousParameters         = SingleAnonymousParameter | MultipleAnonymousParameters .
SingleAnonymousParameter    = identifier .
MultipleAnonymousParameters = "(" AnonymousParameterList ")" .
AnonymousParameterList      = identifier { "," identifier } .
AnonymousFunctionBody       = Expression | FunctionBody .
```
匿名函数的函数体可以是单个表达式。

```xgo
x => math.Sin(x)
(x, y) => x*x + y*y
```
匿名函数的函数体也可以采用普通函数的写法。上面的示例分别等价于下列写法。

```xgo
x => {
	return math.Sin(x)
}

(x, y) => {
	return x*x + y*y
}
```
匿名函数通常作为实参传给函数调用。

```xgo title="sort-slice.xgo"
import "sort"

a := [32, 100, 50, 6, 92]
sort.Slice a, (i, j) => {
	return a[i] < a[j]
}
echo a
```

```text
[6 32 50 92 100]
```
匿名函数省略参数类型和返回值类型，由 XGo 进行类型推断。

函数字面量是_闭包_，可以引用外层函数定义的变量。外层函数和函数字面量共享这些变量。只要这些变量还能被访问，就会继续存活。


### 命令与调用

XGo 支持两种函数和方法调用风格，一种是带圆括号的传统函数调用风格，另一种是省略圆括号的命令风格。

#### 函数调用形式

传统的函数调用语法使用圆括号。

**语法**

```text
CallOrConversion = Operand "(" [ ArgList ] [ "..." ] [ "," ] ")" .
ArgList          = (KwargExpr | LambdaExpr) { "," (KwargExpr | LambdaExpr) } .
KwargExpr        = IDENT "=" LambdaExpr .
```
例如可以这样调用。

```xgo
echo("Hello world")
fmt.Println("Hello, world")
```
#### 命令式调用语法

XGo 推荐命令风格的写法。函数名之后先写空格，再写实参，省略圆括号。

```text
CommandStmt = IDENT [ "." IDENT ] [ SPACE ArgList ] [ "..." ] .
```
下面是命令风格的调用示例。

```xgo
echo "Hello world"
fmt.Println "Hello, world"
```
命令风格的调用可以带限定符（包名或接收者名），也可以省略限定符。

```xgo
echo "unqualified call"
fmt.Println "qualified call"
os.Exit 1
```
使用运算符 `...` 传递可变参数。

```xgo
echo elements...
```
两种调用风格等价，可以互换。XGo 推荐使用类似 shell 命令的命令风格，写法更简洁自然。内置函数 `echo` 是 `println` 的别名，体现了这种面向命令的风格。

#### 关键字参数

XGo 的命令和调用支持按参数名称传递的关键字实参（kwargs）。调用参数较多的函数时，可用 `key=value` 的写法使代码更清晰，更贴近命令行风格。

#### 在元组中使用关键字参数

可以使用元组或元组指针作为关键字参数，以获得类型安全的检查。

```xgo
type Config (timeout, maxRetries int, debug bool)

func run(task int, cfg Config?) {
	if cfg.timeout == 0 {
		cfg.timeout = 30
	}
	if cfg.maxRetries == 0 {
		cfg.maxRetries = 3
	}
    echo "timeout:", cfg.timeout, "maxRetries:", cfg.maxRetries, "debug:", cfg.debug
	echo "task:", task
}

run 100, timeout = 60, maxRetries = 5
run 200
```
#### 在映射中使用关键字参数

映射也可用作关键字参数。

```xgo
func process(opts map[string]any?, args ...any) {
    if name, ok := opts["name"]; ok {
        echo "name:", name
    }
    if age, ok := opts["age"]; ok {
        echo "age:", age
    }
    echo "args:", args
}

process name = "Ken", age = 17              // keyword parameters only
process "extra", 1, name = "Ken", age = 17  // variadic parameters first, then keyword parameters
process                                     // all parameters optional
```
**使用规则**
- 关键字参数必须是可选参数。
- 函数没有可变参数时，关键字参数必须放在最后。有可变参数时，则必须放在倒数第二位。
- 调用函数时，关键字实参必须放在所有普通实参之后，包含传给可变参数的实参。这里的顺序与函数声明中关键字参数和可变参数的顺序不同。

### 运算符

运算符将操作数组合为表达式。

以下为二元运算符。

```xgo
|| && == != < <= > >=
+ - * / %
| & ^ &^ << >>
```
以下为一元运算符。


#### 运算符优先级

_一元运算符_的优先级最高。`++` 和 `--` 构成语句，因而不参与表达式的优先级排序。语句 `*p++` 等价于 `(*p)++`。

_二元运算符_有五个优先级，从高到低依次是乘法类运算符、加法类运算符、比较运算符、`&&`（逻辑与）、`||`（逻辑或）。

```text
Precedence    Operator
    5             *  /  %  <<  >>  &  &^
    4             +  -  |  ^
    3             ==  !=  <  <=  >  >=
    2             &&
    1             ||
```
同一优先级的二元运算符从左到右结合。例如，`x / y * z` 等价于 `(x / y) * z`。

```xgo
+x                         // x
42 + a - b                 // (42 + a) - b
23 + 3*x[i]                // 23 + (3 * x[i])
x <= f()                   // x <= f()
^a >> b                    // (^a) >> b
f() || g()                 // f() || g()
x == y+1 && <-chanInt > 0  // (x == (y+1)) && ((<-chanInt) > 0)
```

_算术运算符_作用于数值，结果与第一个操作数类型相同。四种标准算术运算符（`+`、`-`、`*`、`/`）适用于[整数](#整数字面量)、[浮点数](#浮点数字面量)、[有理数](#有理数字面量)和[复数](#数值类型)类型。`+` 也适用于[字符串](#字符串类型)。按位逻辑运算符和移位运算符只适用于整数。

```text

*    product                integers (including bigint), floats, bigrat, complex values
/    quotient               integers (including bigint), floats, bigrat, complex values
%    remainder              integers (including bigint)

&    bitwise AND            integers (including bigint)
|    bitwise OR             integers (including bigint)
^    bitwise XOR            integers (including bigint)
&^   bit clear (AND NOT)    integers (including bigint)

<<   left shift             integer << integer >= 0
>>   right shift            integer >> integer >= 0
```

#### 比较运算符

_比较运算符_比较两个操作数，返回无类型布尔值。

```xgo
==    equal
!=    not equal
<     less
<=    less or equal
>     greater
>=    greater or equal
```
比较时，其中一个操作数必须能够[赋给](#可赋值性)另一个操作数的类型。

相等性运算符 `==` 和 `!=` 适用于可比较类型。排序运算符 `<`、`<=`、`>` 和 `>=` 适用于有序类型。具体定义和比较结果如下。

* 布尔类型可比较。两个布尔值都为 `true` 或都为 `false` 时相等。
* 整数类型可比较且有序，按照整数的大小比较。
* 浮点数类型可比较且有序，比较遵循 IEEE-754 标准。
* 复数类型可比较。若 `real(u) == real(v)` 且 `imag(u) == imag(v)`，则复数 `u` 和 `v` 相等。
* 字符串类型可比较且有序，按字节进行字典序比较。
* 指针类型可比较。两个指针指向同一变量或均为 `nil` 时相等。指向不同[零大小](#大小与对齐保证)变量的指针可能相等，也可能不等。
* 接口类型可比较。两个接口值的动态类型[相同](#类型标识)且动态值相等，或者二者均为 `nil` 时相等。
* 非接口类型 `X` 的值 `x` 可以与接口类型 `T` 的值 `t` 比较，前提是 `X` 可比较且[实现了](#接口类型) `T`。若 `t` 的动态类型与 `X` 相同，且其动态值等于 `x`，则二者相等。
* 数组的元素类型可比较时，数组类型就可比较。对应元素的值全部相等时，两个数组值才相等。比较按索引升序进行，遇到不同的元素值或比较完所有元素时停止。

如果两个接口值具有相同的动态类型，但该类型不可比较，则比较它们会引发[运行时 panic](#运行时-panic)。这条规则适用于直接比较接口值，也适用于比较元素为接口值的数组或含接口字段的结构体。

切片、映射和函数类型不可比较，但作为特例，它们的值可以与预声明标识符 `nil` 比较。根据以上一般规则，指针值和接口值也可以与 `nil` 比较。

#### 逻辑运算符

逻辑运算符作用于[布尔](#布尔字面量)值，结果的类型与操作数相同。先求左操作数的值，只有条件要求时才求右操作数的值。

```text
&&    conditional AND    p && q  is  "if p then q else false"
||    conditional OR     p || q  is  "if p then true else q"
!     NOT                !p      is  "not p"
```
#### 地址运算符

对类型为 `T` 的操作数 `x`，取地址操作 `&x` 生成指向 `x` 的 `*T` 类型指针。操作数必须可取地址，可以是变量、指针解引用、切片索引、可取地址的结构体的字段选择、或可取地址的数组的索引。作为例外，`x` 也可以是[复合字面量](/zh-CN/docs/reference/full-specification#复合字面量)，并可用圆括号括起。如果 `x` 求值时会引发[运行时 panic](#运行时-panic)，那么对 `&x` 求值也会引发 panic。

对指针类型为 `*T` 的操作数 `x`，指针解引用 `*x` 表示 `x` 指向的类型为 `T` 的[变量](#变量)。当 `x` 为 `nil` 时，尝试对 `*x` 求值会引发[运行时 panic](#运行时-panic)。

```xgo
&x
&a[f(2)]
&Point{2, 3}
*p
*pf(x)

var x *int = nil
*x   // causes a run-time panic
&*x  // causes a run-time panic
```
#### 类型转换

_转换_将表达式的[类型](#类型)改为指定类型。转换可以在源代码中显式写出，也可以由表达式所在的上下文_隐式_进行。

_显式转换_是形如 `T(x)` 的表达式，其中 `T` 是类型，`x` 是可转换为 `T` 的表达式。

```xgo
T(x)
```
如果类型以运算符 `*` 或 `<-` 开头，或以关键字 `func` 开头且没有结果列表，则需要在可能引起歧义时用圆括号括起该类型。

```xgo
*Point(p)        // same as *(Point(p))
(*Point)(p)      // p is converted to *Point
func()(x)        // function signature func() x
(func())(x)      // x is converted to func()
(func() int)(x)  // x is converted to func() int
func() int(x)    // x is converted to func() int (unambiguous)
```
如果[常量](#常量)值 `x` 可用类型 `T` 的值[表示](#可表示性)，则它可转换为 `T`。作为特例，整数常量 `x` 可以显式转换为[字符串类型](#字符串类型)，规则与非常量 `x` 相同。

将常量转换为某种类型，结果为有类型常量。

```xgo
uint(iota)               // iota value of type uint
float32(2.718281828)     // 2.718281828 of type float32
complex128(1)            // 1.0 + 0.0i of type complex128
float32(0.49999999)      // 0.5 of type float32
float64(-1e-1000)        // 0.0 of type float64
string('x')              // "x" of type string
string(0x266c)           // "♬" of type string
myString("foo" + "bar")  // "foobar" of type myString
string([]byte{'a'})      // not a constant: []byte{'a'} is not a constant
(*int)(nil)              // not a constant: nil is not a constant, *int is not a boolean, numeric, or string type
int(1.2)                 // illegal: 1.2 cannot be represented as an int
string(65.0)             // illegal: 65.0 is not an integer constant
```
##### 数值类型之间的转换

转换非常量数值时适用以下规则。

* 在[整数类型](#数值类型)之间转换时，有符号整数先做符号扩展到隐含的无限精度，其他整数做零扩展。随后截断到目标类型的位宽。例如，若 `v := uint16(0x10F0)`，则 `uint32(int8(v)) == 0xFFFFFFF0`。转换始终返回有效值，没有溢出提示。
* 将[浮点数](#数值类型)转换为整数时，丢弃小数部分，即向零截断。
* 将整数或浮点数转换为浮点数类型，或将[复数](#数值类型)转换为另一个复数类型时，结果舍入至目标类型的精度。例如，存储 `float32` 变量 `x` 时可以使用高于 IEEE-754 32 位浮点数的精度，但 `float32(x)` 会将其值舍入至 32 位精度。同样，`x + 0.1` 可以使用高于 32 位的精度，但 `float32(x + 0.1)` 的精度为 32 位。

在涉及浮点数或复数值的所有非常量转换中，即使目标类型无法表示该值，转换仍会成功，结果由具体实现决定。

### 常量表达式

常量表达式只能包含[常量](#常量)操作数，并在编译时求值。

允许使用布尔、数值或字符串类型操作数的地方，也可以使用对应的无类型常量。

常量[比较](#比较运算符)始终产生无类型布尔常量。常量[移位表达式](#运算符)的左操作数若为无类型常量，结果为整数常量。否则结果为与左操作数类型相同的常量，且左操作数必须为[整数类型](#数值类型)。

对无类型常量执行其他运算时，结果为同一种类的无类型常量，包括布尔、整数、浮点数、复数或字符串常量。如果非移位二元运算的两个无类型操作数种类不同，结果采用在下列列表中靠后的操作数种类：整数、rune、浮点数、复数。例如，无类型整数常量除以无类型复数常量，结果为无类型复数常量。

```xgo
const a = 2 + 3.0          // a == 5.0   (untyped floating-point constant)
const b = 15 / 4           // b == 3     (untyped integer constant)
const c = 15 / 4.0         // c == 3.75  (untyped floating-point constant)
const Θ float64 = 3/2      // Θ == 1.0   (type float64, 3/2 is integer division)
const Π float64 = 3/2.     // Π == 1.5   (type float64, 3/2. is float division)
const d = 1 << 3.0         // d == 8     (untyped integer constant)
const e = 1.0 << 3         // e == 8     (untyped integer constant)
const f = int32(1) << 33   // illegal    (constant 8589934592 overflows int32)
const g = float64(2) >> 1  // illegal    (float64(2) is a typed floating-point constant)
const h = "foo" > "bar"    // h == true  (untyped boolean constant)
const j = true             // j == true  (untyped boolean constant)
const k = 'w' + 1          // k == 'x'   (untyped rune constant)
const l = "hi"             // l == "hi"  (untyped string constant)
const m = string(k)        // m == "x"   (type string)
const Σ = 1 - 0.707i       //            (untyped complex constant)
const Δ = Σ + 2.0e-4       //            (untyped complex constant)
const Φ = iota*1i - 1/1i   //            (untyped complex constant)
```
对无类型整数、rune 或浮点数常量调用内置函数 `complex`，会产生无类型复数常量。

```xgo
const ic = complex(0, c)   // ic == 3.75i  (untyped complex constant)
const iΘ = complex(0, Θ)   // iΘ == 1i     (type complex128)
```
常量表达式始终精确求值。中间值和常量本身需要的精度可能远高于语言中任何预声明类型所支持的精度。以下都是合法的声明。

```xgo
const Huge = 1 << 100         // Huge == 1267650600228229401496703205376  (untyped integer constant)
const Four int8 = Huge >> 98  // Four == 4                                (type int8)
```
常量除法或取余运算的除数不得为零。

```xgo
3.14 / 0.0   // illegal: division by zero
```
有类型常量的值必须始终能由该常量类型的值准确[表示](#可表示性)。以下常量表达式不合法。

```xgo
uint(-1)     // -1 cannot be represented as a uint
int(3.14)    // 3.14 cannot be represented as an int
int64(Huge)  // 1267650600228229401496703205376 cannot be represented as an int64
Four * 300   // operand 300 cannot be represented as an int8 (type of Four)
Four * 100   // product 400 cannot be represented as an int8 (type of Four)
```
一元按位取反运算符 `^` 使用的掩码遵循非常量运算的规则。无符号常量的掩码各位均为 1。有符号常量和无类型常量的掩码为 -1。

```xgo
^1         // untyped integer constant, equal to -2
uint8(^1)  // illegal: same as uint8(-2), -2 cannot be represented as a uint8
^uint8(1)  // typed uint8 constant, same as 0xFF ^ uint8(1) = uint8(0xFE)
int8(^1)   // same as int8(-2)
^int8(1)   // same as -1 ^ int8(1) = -2
```
### 短变量声明

短变量声明采用以下语法。

```text
ShortVarDecl = IdentifierList ":=" ExpressionList .
```
它是一种普通[变量声明](#变量声明)的简写，包含初始化表达式，省略类型。

```xgo
"var" IdentifierList "=" ExpressionList .
```
```xgo
i, j := 0, 10
f := func() int { return 7 }
ints := make([]int)
r, w, _ := os.Pipe()  // os.Pipe() returns a connected pair of Files and an error, if any
_, y, _ := coord(p)   // coord() returns three values; only interested in y coordinate
```
短变量声明可以重新声明变量，前提是这些变量已在同一块中以相同类型声明过（如果该块为函数体，也可以声明在参数列表中），且至少有一个[非空白](#空白标识符)变量是新变量。因此，重新声明只能出现在涉及多个变量的短变量声明中。重新声明仅为原变量赋予新值。`:=` 左侧的非空白变量名必须[互不相同](#标识符的唯一性)。

```xgo
field1, offset := nextField(str, 0)
field2, offset := nextField(str, offset)  // redeclares offset
x, y, x := 1, 2, 3                        // illegal: x repeated on left side of :=
```
短变量声明只能出现在函数内部。在 [`if`](#if-语句)、[`for`](#for-语句) 或 [`switch`](#switch-语句) 语句的初始化部分等位置，它可以声明局部临时变量。

### 求值顺序

在包级别，[初始化依赖关系](#包初始化)决定[变量声明](#变量声明)中不同初始化表达式的求值顺序。在其他位置，对表达式、赋值或 [`return` 语句](#return-语句)的[操作数](#操作数)求值时，函数调用、方法调用、接收操作和[二元逻辑运算](#逻辑运算符)均按代码中的从左到右顺序求值。

例如，在以下函数内部的赋值语句中，各项操作有固定的先后顺序。

```xgo
y[f()], ok = g(z || h(), i()+x[j()], <-c), k()
```
函数调用和通信操作的顺序为 `f()`、`h()`（如果 `z` 求值为 `false`）、`i()`、`j()`、`\&lt;-c`、`g()`、`k()`。除语法所要求的先后关系外，这些操作与 `x` 的求值和索引操作、`y` 及 `z` 的求值之间的相对顺序未规定。例如，`g` 必须在实参求值后才能调用。

```xgo
a := 1
f := func() int { a++; return a }
x := [a, f()]      // x may be [1, 2] or [2, 2]: evaluation order between a and f() is not specified
m := {a: 1, a: 2}  // m may be {2: 1} or {2: 2}: evaluation order between the two map assignments is not specified
n := {a: f()}      // n may be {2: 3} or {3: 3}: evaluation order between the key and the value is not specified
```
在包级别，初始化依赖关系优先于不同初始化表达式之间从左到右的规则。每个表达式内部操作数的求值顺序仍遵循该规则。

```xgo
var a, b, c = f() + v(), g(), sqr(u()) + v()

func f() int        { return c }
func g() int        { return a }
func sqr(x int) int { return x*x }

// functions u and v are independent of all other variables and functions
```
函数调用的顺序为 `u()`、`sqr()`、`v()`、`f()`、`v()`、`g()`。

同一表达式中的浮点运算按运算符的结合规则求值。显式括号可以改变默认的结合方式。在 `x + (y + z)` 中，先计算 `y + z`，再与 `x` 相加。

### 自增和自减语句

`++` 和 `--` 语句分别将操作数加上或减去无类型常量 1。与赋值一样，操作数必须可取址，或为映射索引表达式。

```text
IncDecStmt = Expression ( "++" | "--" ) .
```

```xgo
IncDec statement    Assignment
```

### 赋值语句

赋值将[变量](#变量)当前存储的值替换为[表达式](#表达式)指定的新值。赋值语句可以给一个变量赋一个值，也可以给数量相同的多个变量分别赋值。

```text
Assignment = ExpressionList assign_op ExpressionList .
ExpressionList = Expression { "," Expression } .
```
`assign_op` 可以采用以下形式。

```xgo
= += -= |= ^= *= /= %= <<= >>= &= &^=
```
左侧的每个操作数必须[可取址](#地址运算符)、为映射索引表达式，或在 `=` 赋值中使用[空白标识符](#空白标识符)。操作数可以加括号。

```text
x = 1
*p = f()
a[i] = 23
(k) = <-ch  // same as: k = <-ch
```
对于二元[算术运算符](#算术运算符) `op`，_复合赋值_ `x op= y` 等价于 `x = x op (y)`，其中 `x` 只求值一次。`op=` 是一个词法单元。复合赋值左右两侧都必须恰好包含一个产生单个值的表达式。左侧表达式不得为空白标识符。

```xgo
a[i] <<= 2
i &^= 1<<n
```
元组赋值将多值操作产生的各个结果赋给一组变量。它有两种形式。第一种形式的右操作数是单个产生多个值的表达式，例如函数调用、[映射](#映射类型)操作或类型断言。左侧操作数的数量必须与右侧产生的值的数量一致。例如，若 `f` 返回两个值，可以使用以下写法。

```xgo
x, y = f()
```
这条语句将第一个值赋给 `x`，将第二个值赋给 `y`。在第二种形式中，左侧操作数与右侧表达式的数量必须相同。右侧的每个表达式产生一个值，第 n 个表达式的值赋给左侧第 n 个操作数。

```xgo
one, two, three = '一', '二', '三'
```
赋值时，可以通过[空白标识符](#空白标识符)丢弃右侧的值。

```text
_ = x       // evaluate x but ignore it
x, _ = f()  // evaluate f() but ignore second result value
```
赋值分两个阶段进行。首先，左侧索引表达式和[指针间接引用](#地址运算符)的操作数（包括选择器中隐含的指针间接引用）以及右侧表达式，都按[通常的顺序求值](#求值顺序)。然后，按从左到右的顺序执行赋值。

```xgo
a, b = b, a  // exchange a and b

x := [1, 2, 3]
i := 0
i, x[i] = 1, 2  // set i = 1, x[0] = 2

i = 0
x[i], i = 2, 1  // set x[0] = 2, i = 1

x[0], x[0] = 1, 2  // set x[0] = 1, then x[0] = 2 (so x[0] == 2 at end)

x[1], x[3] = 4, 5  // set x[1] = 4, then panic setting x[3] = 5.

i = 2
x = [3, 5, 7]
for i, x[i] <- x {  // set i, x[2] = 0, x[0]
	break
}
// after this loop, i == 0 and x is [3, 5, 3]
```
在赋值中，每个值必须能[赋给](#可赋值性)相应操作数的类型。以下情况有特殊规则。

* 任何有类型的值都可以赋给空白标识符。
* 将无类型常量赋给接口类型变量或空白标识符时，该常量先被隐式[转换](#类型转换)为其[默认类型](#常量)。
* 将无类型布尔值赋给接口类型变量或空白标识符时，该值先被隐式转换为 `bool`。


### `if` 语句

`if` 语句根据布尔表达式的值决定执行哪个分支。表达式为 `true` 时执行 `if` 分支。表达式为 `false` 且存在 `else` 时执行 `else` 分支。

```text
IfStmt = "if" [ SimpleStmt ";" ] Expression Block [ "else" ( IfStmt | Block ) ] .
```
```xgo
if x > 1 {
	x = 1
}
```
可以在表达式之前写一条简单语句。该语句在表达式求值之前执行。

```xgo
if x := f(); x < y {
	return x
} else if x > z {
	return z
} else {
	return y
}
```
### `for` 语句

`for` 语句重复执行一个块，有三种形式。迭代可以由单个条件、`for` 子句或 `range` 子句控制。

```text
ForStmt = "for" [ Condition | ForClause | RangeClause ] Block .
Condition = Expression .
```
#### 带单个条件的 `for` 语句

最简单的 `for` 语句在布尔条件为 `true` 时重复执行语句块。每次迭代前都会对条件求值。省略条件等价于使用布尔值 `true`。

```xgo
for a < b {
	a *= 2
}
```
#### 带 `for` 子句的 `for` 语句

带 `ForClause` 的 `for` 语句仍由条件控制，并可包含初始化语句和后置语句，例如赋值、自增或自减语句。初始化语句可以是[短变量声明](#短变量声明)，后置语句不得使用这种声明。

```text
ForClause = [ InitStmt ] ";" [ Condition ] ";" [ PostStmt ] .
InitStmt = SimpleStmt .
PostStmt = SimpleStmt .
```
```xgo
for i := 0; i < 10; i++ {
	f(i)
}
```
如果初始化语句非空，它在首次迭代的条件求值之前执行一次。如果后置语句非空，它在每次实际执行循环体之后执行。`ForClause` 中的任一部分均可省略。仅使用条件时可省略[分号](#分号)，其他情况必须保留。省略条件等价于使用布尔值 `true`。

```xgo
for cond { S() }    is the same as    for ; cond ; { S() }
for      { S() }    is the same as    for true     { S() }
```
自 Go 1.22 起，每轮迭代都有独立声明的变量。第一轮使用初始化语句声明的变量。后续每一轮使用在执行后置语句之前隐式声明的变量，其初始值为上一轮相应变量在该时刻的值。

```xgo
var prints []func()
for i := 0; i < 5; i++ {
	prints = append(prints, func() { println(i) })
	i++
}
for _, p := range prints {
	p()
}
```
输出如下。

```text
1
3
5
```
在 [Go 1.22] 之前，各轮迭代共享同一组变量。按此规则，上面的示例输出如下。

```text
6
6
6
```

### `switch` 语句

`switch` 语句按多个分支执行。它将表达式或类型与 `switch` 中各 `case` 进行比较，以确定执行哪个分支。

```text
SwitchStmt = ExprSwitchStmt | TypeSwitchStmt .
```
`switch` 有表达式和类型两种形式。表达式 `switch` 的 `case` 包含表达式，与 `switch` 表达式的值比较。类型 `switch` 的 `case` 包含类型，与使用专门语法标记的 `switch` 表达式的类型比较。每条 `switch` 语句的 `switch` 表达式恰好求值一次。

#### 表达式 `switch`

在表达式 `switch` 中，先对 `switch` 表达式求值，再从左到右、从上到下对各 `case` 表达式求值。`case` 表达式可以是非常量。第一个与 `switch` 表达式的值相等的 `case` 触发其语句，其他 `case` 被跳过。若没有匹配的 `case` 且存在 `default`，则执行 `default` 中的语句。最多有一个 `default`，其位置不限。省略 `switch` 表达式等价于使用布尔值 `true`。

```text
ExprSwitchStmt = "switch" [ SimpleStmt ";" ] [ Expression ] "{" { ExprCaseClause } "}" .
ExprCaseClause = ExprSwitchCase ":" StatementList .
ExprSwitchCase = "case" ExpressionList | "default" .
```
若 `switch` 表达式求值为无类型常量，先将它隐式[转换](#类型转换)为其[默认类型](#常量)。预声明的无类型值 `nil` 不能用作 `switch` 表达式。`switch` 表达式的类型必须[可比较](#比较运算符)。

若 `case` 表达式是无类型的，先将它隐式[转换](#类型转换)为 `switch` 表达式的类型。对于每个可能已转换的 `case` 表达式 `x` 和 `switch` 表达式的值 `t`，`x == t` 必须是有效的[比较](#比较运算符)。

可以把 `switch` 表达式理解为声明和初始化一个未显式指定类型的临时变量 `t`，再将每个 `case` 表达式 `x` 与 `t` 的值进行相等比较。

`case` 或 `default` 子句最后一条非空语句可以是[`fallthrough` 语句](#fallthrough-语句)，也可以[带标签](#带标签的语句)。它把控制流从本子句的末尾转移到下一子句的第一条语句。没有这条语句时，控制流转到 `switch` 语句末尾。在表达式 `switch` 中，最后一个子句以外的任何子句都可以以 `fallthrough` 结束。

可以在 `switch` 表达式前写一条简单语句。该语句在表达式求值之前执行。

```xgo
switch tag {
default: s3()
case 0, 1, 2, 3: s1()
case 4, 5, 6, 7: s2()
}

switch x := f(); {  // missing switch expression means "true"
case x < 0: return -x
default: return x
}

switch {
case x < y: f1()
case x < z: f2()
case x == 4: f3()
}
```
**实现限制**。编译器可以禁止多个 `case` 表达式求值为同一个常量。例如，目前的编译器禁止在 `case` 表达式中重复使用相同的整数、浮点数或字符串常量。

#### 类型 switch

类型 `switch` 比较类型，其他方面类似表达式 `switch`。它的 `switch` 表达式具有类型断言的形式，其中用关键字 `type` 取代具体类型。

```xgo
switch x.(type) {
// cases
}
```
各 `case` 会将具体的类型 `T` 与表达式 `x` 的动态类型匹配。与类型断言一样，`x` 必须为接口类型，且不能是类型参数。每个 `case` 中列出的非接口类型 `T` 都必须实现 `x` 的接口类型。类型 `switch` 的各 `case` 中列出的类型必须互不相同。

```text
TypeSwitchStmt  = "switch" [ SimpleStmt ";" ] TypeSwitchGuard "{" { TypeCaseClause } "}" .
TypeSwitchGuard = [ identifier ":=" ] PrimaryExpr "." "(" "type" ")" .
TypeCaseClause  = TypeSwitchCase ":" StatementList .
TypeSwitchCase  = "case" TypeList | "default" .
```
`TypeSwitchGuard` 可以包含[短变量声明](#短变量声明)。使用此形式时，该变量在每个子句的[隐式块](#代码块)中、`TypeSwitchCase` 的末尾声明。只列出一个类型的 `case` 子句中，变量具有该类型。其他子句中，变量具有 `TypeSwitchGuard` 中表达式的类型。

`case` 可以用预声明的标识符 `nil` 取代类型。`TypeSwitchGuard` 中的表达式是 `nil` 接口值时，会选中此 `case`。最多只能有一个 `nil` 分支。

给定 `any` 类型的表达式 `x`，考虑以下类型 `switch`。

```text
switch i := x.(type) {
case nil:
	printString("x is nil")                // type of i is type of x (any)
case int:
	printInt(i)                            // type of i is int
case float64:
	printFloat64(i)                        // type of i is float64
case func(int) float64:
	printFunction(i)                       // type of i is func(int) float64
case bool, string:
	printString("type is bool or string")  // type of i is type of x (any)
default:
	printString("don't know the type")     // type of i is type of x (any)
}
```
它可以改写成以下形式。

```xgo
v := x  // x is evaluated exactly once
if v == nil {
	i := v                                 // type of i is type of x (any)
	printString("x is nil")
} else if i, isInt := v.(int); isInt {
	printInt(i)                            // type of i is int
} else if i, isFloat64 := v.(float64); isFloat64 {
	printFloat64(i)                        // type of i is float64
} else if i, isFunc := v.(func(int) float64); isFunc {
	printFunction(i)                       // type of i is func(int) float64
} else {
	_, isBool := v.(bool)
	_, isString := v.(string)
	if isBool || isString {
		i := v                         // type of i is type of x (any)
		printString("type is bool or string")
	} else {
		i := v                         // type of i is type of x (any)
		printString("don't know the type")
	}
}
```
可以在类型切换的判定式之前写一条简单语句。该语句在判定式求值之前执行。

类型 `switch` 中不得使用 `fallthrough` 语句。


### 带标签的语句

带标签的语句可以作为 `goto`、`break` 或 `continue` 语句的目标。

```text
LabeledStmt = Label ":" Statement .
Label       = identifier .
```
```xgo
Error:
	log.Panic("error encountered")
```
### `break` 语句

`break` 语句终止同一函数内最内层的 [`for`](#for-语句) 或 [`switch`](#switch-语句) 语句。

```text
BreakStmt = "break" [ Label ] .
```
如果指定标签，该标签必须属于一个包围 `break` 的 `for` 或 `switch` 语句。`break` 会终止该标签对应的语句。

```xgo
OuterLoop:
	for i = 0; i < n; i++ {
		for j = 0; j < m; j++ {
			switch a[i][j] {
			case nil:
				state = Error
				break OuterLoop
			case item:
				state = Found
				break OuterLoop
			}
		}
	}
```
### `continue` 语句

`continue` 语句将控制流转移到同一函数内最内层 [`for`](#for-语句) 循环块的末尾，开始下一轮迭代。

```text
ContinueStmt = "continue" [ Label ] .
```
如果指定标签，该标签必须属于一个包围 `continue` 的 `for` 语句。`continue` 会使该标签对应的循环进入下一轮迭代。

```xgo
RowLoop:
	for y, row := range rows {
		for x, data := range row {
			if data == endOfRow {
				continue RowLoop
			}
			row[x] = data + bias(x, y)
		}
	}
```
### `fallthrough` 语句

`fallthrough` 语句将控制流转移到表达式 [`switch`](#switch-语句) 中下一条 `case` 子句的第一条语句。它只能用作当前子句最后一条非空语句。

```text
FallthroughStmt = "fallthrough" .
```
### `goto` 语句

`goto` 语句将控制流转移到同一函数内带有对应标签的语句。

```text
GotoStmt = "goto" Label .
```
```xgo
goto Error
```
执行 `goto` 后，目标位置的[作用域](#声明与作用域)不得包含任何在 `goto` 处尚不可见的变量。以下示例说明了这种情况。

```xgo
	goto L  // BAD
	v := 3
L:
```
这段代码有误，因为跳转到标签 `L` 时会跳过变量 `v` 的创建。

位于[块](#代码块)外部的 `goto` 语句不能跳转到该块内部的标签。以下是一个示例。

```xgo
if n%2 == 1 {
	goto L1  // BAD
}
for n > 0 {
	f()
	n--
L1:
	f()
	n--
}
```
这段代码有误，因为标签 `L1` 位于 `for` 语句的块中，而 `goto` 位于该块之外。

### `return` 语句

函数 `F` 中的 `return` 语句终止 `F` 的执行，并可提供一个或多个结果值。`F` 通过 [`defer`](#defer-语句) 注册的所有函数都在 `F` 返回调用者之前执行。

```text
ReturnStmt = "return" [ ExpressionList ] .
```
在没有结果类型的函数中，`return` 语句不得指定结果值。

```xgo
func noResult() {
	return
}
```
有结果类型的函数可以用三种方式返回值。

* 在 `return` 语句中显式列出返回值。每个表达式必须产生单个值，且其值必须能够[赋给](#可赋值性)函数结果类型中的对应元素。

```xgo
func simpleF() int {
	return 2
}

func complexF1() (re float64, im float64) {
	return -7.0, -4.0
}
```
* 在 `return` 语句的表达式列表中写入一个返回多值的函数调用。效果相当于先将该调用返回的每个值赋给一个对应类型的临时变量，再用一条列出这些变量的 `return` 语句，之后按上一种方式的规则处理。

```xgo
func complexF2() (re float64, im float64) {
	return complexF1()
}
```
* 如果函数的结果类型为[结果形参](#函数类型)指定了名称，可以省略表达式列表。结果形参可像普通局部变量一样按需赋值。`return` 语句返回这些变量的值。

```xgo
func complexF3() (re float64, im float64) {
	re = 7.0
	im = 4.0
	return
}
```
进入函数时，所有结果值都会初始化为其类型的[零值](#零值-1)，与声明方式无关。指定结果值的 `return` 语句在执行任何延迟调用之前设置结果形参。

**实现限制**。若 `return` 处的[作用域](#声明与作用域)内存在与某个结果形参同名的其他实体，例如常量、类型或变量，编译器可以禁止该 `return` 语句使用空的表达式列表。

```xgo
func f(n int) (res int, err error) {
	if _, err := f(n-1); err != nil {
		return  // invalid return statement: err is shadowed
	}
	return
}
```
### `defer` 语句

`defer` 语句安排一次函数调用，将实际执行推迟到所在函数返回时。所在函数可能因执行 [`return` 语句](#return-语句)、到达函数体末尾，或因对应的 goroutine 正在[处理 panic](#处理-panic)而返回。

```text
DeferStmt = "defer" Expression .
```
表达式必须为函数或方法调用，且不得用括号包住整个调用。内置函数调用与[表达式语句](#表达式语句)中的调用受相同限制。

每次执行 `defer` 语句时，函数值和调用实参都会[照常求值](#求值顺序)并重新保存。延迟函数将在所在函数返回前立即按注册的逆序调用。若所在函数通过显式 [`return` 语句](#return-语句)返回，则先设置结果形参，再执行延迟函数，最后返回调用者。若延迟的函数值求值为 `nil`，程序会在实际调用该函数时[触发 panic](#运行时-panic)。

例如，如果延迟调用的是[函数字面量](#函数字面量)，且所在函数的[具名结果形参](#函数类型)在该字面量内可见，延迟函数就可以在这些结果返回之前访问和修改它们。延迟函数返回的任何值都会在该函数执行完毕时丢弃。另见[处理 panic](#处理-panic)。

```xgo
lock(l)
defer unlock(l)  // unlocking happens before surrounding function returns

// f returns 42
func f() (result int) {
	defer func() {
		// result is accessed after it was set to 6 by the return statement
		result *= 7
	}()
	return 6
}
```

## 内置函数

内置函数是[预声明的](#预声明标识符)。它们的调用方式与其他函数相同，但其中一些函数的首个实参是类型。

内置函数没有标准的 Go 类型，只能出现在[调用表达式](#命令与调用)中，不能用作函数值。

### 追加与复制切片

内置函数 `append` 和 `copy` 用于常见切片操作。两个函数的结果都不受实参所引用的内存是否重叠的影响。

[可变参数](#函数类型)函数 `append` 将零个或多个值 `x` 追加到切片 `s`，并返回与 `s` 类型相同的结果切片。`s` 的[底层类型](#底层类型)必须是切片类型 `[]E`。将这些值 `x` 传给类型为 `...E` 的形参时，适用相应的[参数传递规则](#命令与调用)。若 `s` 的底层类型为 `[]byte`，`append` 还接受底层类型为字节切片或字符串的第二个实参，并在其后加上 `...`。这种写法会追加该切片或字符串中的字节。

```xgo
append(s S, x ...E) S  // underlying type of S is []E
```
若 `s` 的容量不足以容纳追加的值，`append` 会[分配](#分配)一个足够大的新底层数组，保存原有切片元素和追加的值。容量充足时，`append` 复用原底层数组。

```xgo
s0 := [0, 0]
s1 := append(s0, 2)                // append a single element     s1 is [0, 0, 2]
s2 := append(s1, 3, 5, 7)          // append multiple elements    s2 is [0, 0, 2, 3, 5, 7]
s3 := append(s2, s0...)            // append a slice              s3 is [0, 0, 2, 3, 5, 7, 0, 0]
s4 := append(s3[3:6], s3[2:]...)   // append overlapping slice    s4 is [3, 5, 7, 2, 3, 5, 7, 0, 0]

var t []any
t = append(t, 42, 3.1415, "foo")   //                             t is [42, 3.1415, "foo"]

var b []byte
b = append(b, "bar"...)            // append string contents      b is []byte("bar")
```
`copy` 从源切片 `src` 向目标切片 `dst` 复制元素，并返回复制的元素数量。两个实参的[底层类型](#底层类型)都必须是切片类型，且元素类型必须[相同](#类型标识)。复制的元素数量是 `len(src)` 与 `len(dst)` 中的较小值。如果目标的底层类型是 `[]byte`，`copy` 也接受底层类型为字节切片或字符串的源实参，并将源中的字节复制到目标字节切片。

```xgo
copy(dst, src []T) int
copy(dst []byte, src string) int
```
下面是几个示例。

```xgo
a := [0, 1, 2, 3, 4, 5, 6, 7]
s := make([]int, 6)
b := make([]byte, 5)
n1 := copy(s, a)                // n1 == 6, s is []int{0, 1, 2, 3, 4, 5}
n2 := copy(s, s[2:])            // n2 == 4, s is []int{2, 3, 4, 5, 4, 5}
n3 := copy(b, "Hello, World!")  // n3 == 5, b is []byte("Hello")
```
### clear

内置函数 `clear` 接收 `map` 或 `slice` 类型的实参，删除映射中的所有元素或将切片的所有元素清零。

```text
Call        Argument type     Result

clear(m)    map[K]T           deletes all entries, resulting in an
                              empty map (len(m) == 0)

clear(s)    []T               sets all elements up to the length of
                              s to the zero value of T
```
如果映射或切片为 `nil`，`clear` 不执行任何操作。

### 操作复数

有三个函数可用于构造和拆解复数。内置函数 `complex` 通过浮点类型的实部和虚部构造复数。`real` 和 `imag` 分别提取复数的实部和虚部。

```xgo
complex(realPart, imaginaryPart floatT) complexT
real(complexT) floatT
imag(complexT) floatT
```
实参类型和返回值类型相互对应。`complex` 的两个实参必须是同一种[浮点类型](#数值类型)，返回类型是实部和虚部都采用该浮点类型的[复数类型](#数值类型)。`float32` 实参对应 `complex64`，`float64` 实参对应 `complex128`。如果一个实参求值为无类型常量，则先将其隐式[转换](#类型转换)为另一个实参的类型。如果两个实参都求值为无类型常量，则它们必须是非复数，或虚部均为零。此时函数返回无类型复数常量。

`real` 和 `imag` 的实参必须为复数类型，返回值为对应的浮点类型。`complex64` 实参对应 `float32`，`complex128` 实参对应 `float64`。如果实参求值为无类型常量，该常量必须为数值，此时函数返回无类型浮点常量。

`real` 和 `imag` 合在一起构成 `complex` 的逆运算。设 `z` 的复数类型为 `Z`，则 `z == Z(complex(real(z), imag(z)))`。

如果这些函数的操作数都是常量，结果也是常量。

```xgo
var a = complex(2, -2)             // complex128
const b = complex(1.0, -1.4)       // untyped complex constant 1 - 1.4i
x := float32(math.Cos(math.Pi/2))  // float32
var c64 = complex(5, -x)           // complex64
var s int = complex(1, 0)          // untyped complex constant 1 + 0i can be converted to int
_ = complex(1, 2<<s)               // illegal: 2 assumes floating-point type, cannot shift
var rl = real(c64)                 // float32
var im = imag(a)                   // float64
const c = imag(b)                  // untyped constant -1.4
_ = imag(3 << s)                   // illegal: 3 assumes complex type, cannot shift
```
### 删除映射元素

内置函数 `delete` 从[映射](#映射类型) `m` 中移除键 `k` 对应的元素。`k` 必须可以[赋值](#可赋值性)给 `m` 的键类型。

```xgo
delete(m, k)  // remove element m[k] from map m
```
如果映射 `m` 为 nil，或 `m[k]` 不存在，`delete` 不执行任何操作。

### 长度和容量

内置函数 `len` 和 `cap` 接受多种类型的参数，结果类型为 `int`。实现保证结果在 `int` 的表示范围内。

```xgo
Call      Argument type    Result

len(s)    string type      string length in bytes
          [n]T, *[n]T      array length (== n)
          []T              slice length
          map[K]T          map length (number of defined keys)
          type parameter   see below

cap(s)    [n]T, *[n]T      array length (== n)
          []T              slice capacity
          type parameter   see below
```
切片的容量是从切片起点开始，底层数组中已分配空间能容纳的元素数。以下关系始终成立。

```xgo
0 <= len(s) <= cap(s)
```
`nil` 切片和映射的长度为 `0`，`nil` 切片的容量也为 `0`。

若 s 是字符串常量，`len(s)` 是[常量](#常量)。若 `s` 的类型为数组或数组指针，且表达式 `s` 不含非常量[函数调用](#命令与调用)，则 `len(s)` 和 `cap(s)` 都是常量，`s` 不会被求值。其他情况下，这些调用的结果不是常量，`s` 会被求值。

```xgo
const (
	c1 = imag(2i)                    // imag(2i) = 2.0 is a constant
	c2 = len([10]float64{2})         // [10]float64{2} contains no function calls
	c3 = len([10]float64{c1})        // [10]float64{c1} contains no function calls
	c4 = len([10]float64{imag(2i)})  // imag(2i) is a constant and no function call is issued
	c5 = len([10]float64{imag(z)})   // invalid: imag(z) is a (non-constant) function call
)
var z complex128
```
创建切片和映射

内置函数 `make` 接受类型 `T`，后面可以跟一组由该类型决定的表达式。`T` 的[底层类型](#底层类型)必须为切片或映射。返回值的类型为 `T`。分配的内存按[初始值](#零值-1)一节所述进行初始化。

```xgo
Call             Underlying type    Result

make(T, n)       slice        slice of type T with length n and capacity n
make(T, n, m)    slice        slice of type T with length n and capacity m

make(T)          map          map of type T
make(T, n)       map          map of type T with initial space for approximately n elements
```
大小参数 `n` 和 `m` 必须是[整数类型](#数值类型)、[类型集](#接口类型)只包含整数的类型，或无类型常量。常量大小必须非负且可由 `int` [表示](#可表示性)；无类型常量在这里取 `int` 类型。如果同时给出 `n` 和 `m` 且两者均为常量，须满足 `n` 不大于 `m`。对于切片，若运行时 `n` 为负数或大于 `m`，会发生[运行时 panic](#运行时-panic)。

```xgo
s := make([]int, 10, 100)       // slice with len(s) == 10, cap(s) == 100
s := make([]int, 1e3)           // slice with len(s) == cap(s) == 1000
s := make([]int, 1<<63)         // illegal: len(s) is not representable by a value of type int
s := make([]int, 10, 0)         // illegal: len(s) > cap(s)
m := make(map[string]int, 100)  // map with initial space for approximately 100 elements
```
以映射类型调用 `make` 并提供大小提示 `n` 时，会创建一个映射，并预留可容纳 `n` 个元素的初始空间。具体行为依赖实现。


### 分配

内置函数 `new` 接受类型 `T`，在运行时为该类型的一个[变量](#变量)分配存储空间，返回[指向](#指针类型)该变量的 `*T` 类型值。变量的初始化规则见[初始值](#零值-1)一节。

```xgo
new(T)
```
例如：

```xgo
new(int)
```
这会为一个 `int` 变量分配空间，将其初始化为 `0`，然后返回包含该地址的 `*int` 类型值。


### `min` 和 `max`

内置函数 `min` 和 `max` 分别求一组[有序类型](#比较运算符)实参的最小值和最大值。每次调用的实参数量固定，至少需要一个。

类型规则与[运算符](#运算符)相同。对于[有序](#比较运算符)实参 `x` 和 `y`，如果 `x + y` 合法，`min(x, y)` 也合法，且两者类型相同。`max` 同理。所有实参都是常量时，结果也是常量。

```xgo
var x, y int
m := min(x)                 // m == x
m := min(x, y)              // m is the smaller of x and y
m := max(x, y, 10)          // m is the larger of x and y but at least 10
c := max(1, 2.0, 10)        // c == 10.0 (floating-point kind)
f := max(0, float32(x))     // type of f is float32
var s []string
_ = min(s...)               // invalid: slice arguments are not permitted
t := max("", "foo", "bar")  // t == "foo" (string kind)
```
对于数值实参，如果把所有 `NaN` 视为相等，则 `min` 和 `max` 都满足交换律和结合律。

```text
min(x, y)    == min(y, x)
min(x, y, z) == min(min(x, y), z) == min(x, min(y, z))
```
对浮点实参中的负零、`NaN` 和无穷大，适用下列规则。

```xgo
x        y    min(x, y)    max(x, y)

-0.0    0.0         -0.0          0.0    // negative zero is smaller than (non-negative) zero
-Inf      y         -Inf            y    // negative infinity is smaller than any other number
+Inf      y            y         +Inf    // positive infinity is larger than any other number
 NaN      y          NaN          NaN    // if any argument is a NaN, the result is a NaN
```
对字符串实参，按字节作字典序比较。`min` 返回最小值第一次出现时的实参，`max` 返回最大值第一次出现时的实参。

```xgo
min(x, y)    == if x <= y then x else y
min(x, y, z) == min(min(x, y), z)
```
### 处理 panic

内置函数 `panic` 和 `recover` 用于报告和处理[运行时 panic](#运行时-panic)以及程序自行定义的错误情况。

```xgo
func panic(any)
func recover() any
```
函数 `F` 执行期间显式调用 `panic`，或发生[运行时 panic](#运行时-panic)，都会中止 `F` 的正常执行。随后照常执行 `F` 登记的[延迟调用](#defer-语句)，再执行其调用方登记的延迟调用，逐层回溯，直到当前 goroutine 最外层函数的延迟调用。若整个过程未被恢复，程序终止并报告错误情况，包括传给 panic 的值。这个终止过程称为 *panicking*。

```xgo
panic(42)
panic("unreachable")
panic(Error("cannot parse"))
```
`recover` 可以控制正在发生 panic 的 goroutine。假设函数 `G` 将调用 `recover` 的函数 `D` 登记为延迟调用，而同一 goroutine 中的某个函数发生了 panic。当执行延迟调用到达 `D` 时，`recover` 返回传给 panic 的值。若 `D` 正常返回且没有引发新的 panic，原 panic 的展开过程就会停止。`G` 与 panic 调用之间各函数的执行状态被丢弃，程序恢复正常执行。接着运行 `G` 在登记 `D` 之前登记的延迟调用，最后 `G` 返回到其调用方。

如果 goroutine 未发生 panic，或延迟执行的函数没有直接调用 `recover`，则 `recover` 返回 `nil`。反之，在发生 panic 的 goroutine 内，由延迟执行的函数直接调用 recover 时，保证返回值非 `nil`。为确保这一点，以值为 `nil` 的接口或无类型 nil 调用 panic 会引发[运行时 panic](#运行时-panic)。

下例中的 `protect` 调用传入的函数 `g`，并保护调用者免受 `g` 引发的运行时 panic 影响。

```xgo
func protect(g func()) {
	defer func() {
		log.Println("done")  // Println executes normally even if there is a panic
		if x := recover(); x != nil {
			log.Printf("run time panic: %v", x)
		}
	}()
	log.Println("start")
	g()
}
```

## 代码块

*块*是成对花括号围住的一组声明和语句，可以为空。

```text
Block = "{" StatementList "}" .
StatementList = { Statement ";" } .
```
除源码中明确书写的块以外，还有以下隐式块。

* *全域块*涵盖全部 XGo 源码。
* 每个[包](#包)有一个*包块*，包含该包的全部 XGo 源码。
* 每个文件有一个*文件块*，包含该文件的全部 XGo 源码。
* 每条 [if](#if-语句)、[for](#for-语句) 或 [switch](#switch-语句) 语句都位于自己的隐式块中。
* [switch](#switch-语句) 中的每个子句都构成一个隐式块。

块可以嵌套，并决定[作用域](#声明与作用域)。


## 声明与作用域

*声明*将非[空白](#空白标识符)标识符绑定到[常量](#常量)、[类型](#类型)、[变量](#变量)、函数、[标签](#带标签的语句)或[包](#包)。程序中的标识符都必须声明。同一个块中不能重复声明标识符，也不能在文件块及其包块中同时声明同一标识符。

[空白标识符](#空白标识符)可以与其他标识符一样出现在声明中，但不会建立绑定，因此也没有被声明。在包块中，标识符 `init` 只能用于声明[初始化函数](#包初始化)，同样不会建立新的绑定。

```text
Declaration   = ConstDecl | TypeDecl | VarDecl .
TopLevelDecl  = Declaration | FunctionDecl .
```
已声明标识符的作用域是源码中该标识符指代指定常量、类型、变量、函数、标签或包的范围。

XGo 以块为单位确定词法作用域。

* [预声明标识符](#预声明标识符)的作用域是全域块。
* 在顶层（所有函数之外）声明的常量、类型、变量或函数标识符，其作用域是包块。
* 导入包的包名，其作用域是包含该导入声明的文件块。
* 表示函数参数或结果变量的标识符，其作用域是函数体。
* 函数内声明的常量或变量标识符，其作用域始于对应的 `ConstSpec` 或 `VarSpec` 末尾（短变量声明则从 `ShortVarDecl` 末尾开始），终于直接包含该声明的最内层块的末尾。

外层块中声明的标识符可以在内层块中重新声明。在内层声明的作用域内，该标识符指代内层声明的实体。

[包子句](#package-子句)不会声明标识符，其中的包名不属于任何作用域。它标明哪些文件属于同一个[包](#包)，并给出导入该包时使用的默认名称。

### 标签作用域

标签由[带标签语句](#带标签的语句)声明，可以在 [break](#break-语句)、[continue](#continue-语句) 和 [goto](#goto-语句) 语句中使用。定义后从未使用的标签不合法。标签不按块划分作用域，且不会与同名的普通标识符冲突。标签作用于声明它的整个函数体，但不包括嵌套函数的函数体。


### 空白标识符

*空白标识符*由下划线 `_` 表示，作为普通非空白标识符的匿名占位符。它在[声明](#声明与作用域)中、作为[操作数](#操作数)时，以及在[赋值语句](#赋值语句)中具有特殊含义。

### 预声明标识符

下列标识符隐式声明在[全域块](#代码块)中。

```xgo
Types:
	any bigint bigrat bool byte comparable
	complex64 complex128 error float32 float64
	int int8 int16 int32 int64 rune string
	uint uint8 uint16 uint32 uint64 uintptr

Constants:
	true false iota

Zero value:
	nil

Functions:
	append cap clear close complex copy delete echo imag len
	make max min new panic print printf println real recover // TODO(xsw): more
```
### 导出标识符

标识符可以*导出*，供其他包访问。同时满足以下两个条件时，标识符即为导出标识符。

* 名称的首字符是 Unicode 大写字母（字符类别 Lu）。
* 标识符声明于[包块](#代码块)，或为[字段名](/zh-CN/docs/reference/full-specification#结构体类型)或方法名。

其余标识符均不导出。

### 标识符的唯一性

在一组标识符中，若某个标识符*不同于*组内其他每个标识符，就称其*唯一*。两个标识符拼写不同，或位于不同的[包](#包)且均未[导出](#导出标识符)时，视为不同。其他情形视为相同。

### 常量声明

常量声明将一列标识符（常量名）分别绑定到一列[常量表达式](#常量表达式)的值。两列数量必须相等，左侧第 n 个标识符对应右侧第 n 个表达式的值。

```text
ConstDecl      = "const" ( ConstSpec | "(" { ConstSpec ";" } ")" ) .
ConstSpec      = IdentifierList [ [ Type ] "=" ExpressionList ] .

IdentifierList = identifier { "," identifier } .
ExpressionList = Expression { "," Expression } .
```
若显式给出类型，则所有常量均取该类型，各表达式必须可[赋值](#可赋值性)给该类型，并且该类型不能是类型参数。若省略类型，则每个常量取对应表达式自身的类型。如果表达式的值是无类型[常量](#常量)，声明得到的常量也保持无类型，标识符表示相应常量值。例如，浮点字面量声明的常量是浮点常量，即使其小数部分为零。

```xgo
const Pi float64 = 3.14159265358979323846
const zero = 0.0         // untyped floating-point constant
const (
	size int64 = 1024
	eof        = -1  // untyped integer constant
)
const a, b, c = 3, 4, "foo"  // a = 3, b = 4, c = "foo", untyped integer and string constants
const u, v float32 = 0, 3    // u = 0.0, v = 3.0
```
在用圆括号括起的常量声明列表中，除第一个 ConstSpec 外都可以省略表达式列表。省略相当于将前面最近的非空表达式列表及其显式类型（如有）原样替入当前位置。标识符数量必须与该列表的表达式数相同。配合 [iota 常量生成器](#iota)，这一规则便于声明连续的值。

```xgo
const (
	Sunday = iota
	Monday
	Tuesday
	Wednesday
	Thursday
	Friday
	Partyday
	numberOfDays  // this constant is not exported
)
```
### `iota`

在[常量声明](#常量声明)中，预声明标识符 iota 依次表示无类型整数[常量](#常量)。其值为当前 [ConstSpec](#常量声明) 在该常量声明中的索引，从零开始。可借此构造一组相关常量。

```xgo
const (
	c0 = iota  // c0 == 0
	c1 = iota  // c1 == 1
	c2 = iota  // c2 == 2
)

const (
	a = 1 << iota  // a == 1  (iota == 0)
	b = 1 << iota  // b == 2  (iota == 1)
	c = 3          // c == 3  (iota == 2, unused)
	d = 1 << iota  // d == 8  (iota == 3)
)

const (
	u         = iota * 42  // u == 0     (untyped integer constant)
	v float64 = iota * 42  // v == 42.0  (float64 constant)
	w         = iota * 42  // w == 84    (untyped integer constant)
)

const x = iota  // x == 0
const y = iota  // y == 0
```
同一个 ConstSpec 中多次使用 iota，其值总是相同。

```xgo
const (
	bit0, mask0 = 1 << iota, 1<<iota - 1  // bit0 == 1, mask0 == 0  (iota == 0)
	bit1, mask1                           // bit1 == 2, mask1 == 1  (iota == 1)
	_, _                                  //                        (iota == 2, unused)
	bit3, mask3                           // bit3 == 8, mask3 == 7  (iota == 3)
)
```
最后一个例子使用了最近一个非空表达式列表的[隐式重复](#常量声明)。

### 类型声明

类型声明将标识符（即*类型名*）绑定到一个[类型](#类型)。它包括别名声明和类型定义两种形式。

```text
TypeDecl = "type" ( TypeSpec | "(" { TypeSpec ";" } ")" ) .
TypeSpec = AliasDecl | TypeDef .
```
#### 别名声明

别名声明将标识符绑定到指定类型。

```text
AliasDecl = identifier "=" Type .
```
在该标识符的[作用域](#声明与作用域)内，它是此类型的别名。

```xgo
type (
	nodeList = []*Node  // nodeList and []*Node are identical types
	Polar    = polar    // Polar and polar denote identical types
)
```
#### 类型定义

类型定义创建一个新的、独立的类型。新类型与给定类型具有相同的[底层类型](#底层类型)和操作。定义同时将标识符（即*类型名*）绑定到新类型。

```text
TypeDef = identifier Type .
```
这种新类型称为*定义类型*。它与其他所有类型均[不同](#类型标识)，包括创建它所依据的类型。

```xgo
type (
	Point struct{ x, y float64 }  // Point and struct{ x, y float64 } are different types
	polar Point                   // polar and Point denote different types
)

type TreeNode struct {
	left, right *TreeNode
	value any
}

type Block interface {
	BlockSize() int
	Encrypt(src, dst []byte)
	Decrypt(src, dst []byte)
}
```
可以通过类型定义声明不同的布尔、数值或字符串类型。

```xgo
type TimeZone int

const (
	EST TimeZone = -(5 + iota)
	CST
	MST
	PST
)
```
### 变量声明

变量声明创建一个或多个[变量](#变量)，将相应的标识符绑定到它们，并分别指定类型和初始值。

```text
VarDecl     = "var" ( VarSpec | "(" { VarSpec ";" } ")" ) .
VarSpec     = IdentifierList ( Type [ "=" ExpressionList ] | "=" ExpressionList ) .
```
```xgo
var i int
var U, V, W float64
var k = 0
var x, y float32 = -1, -2
var (
	i       int
	u, v, s = 2.0, 3.0, "bar"
)
var re, im = complexSqrt(-1)
var _, found = entries[name]  // map lookup; only interested in "found"
```
若提供表达式列表，则按[赋值语句](#赋值语句)的规则用相应表达式初始化变量。否则各变量初始化为其类型的[零值](#零值-1)。

若声明给出类型，各变量取该类型。否则变量取对应初始值的类型。无类型常量先隐式[转换](#类型转换)为其[默认类型](#常量)，无类型布尔值先隐式转换为 `bool`。未显式指定类型时，不能用预声明值 `nil` 初始化变量。

```xgo
var d = math.Sin(0.5)  // d is float64
var i = 42             // i is int
var t, ok = x.(T)      // t is T, ok is bool
var n = nil            // illegal
```
实现限制：编译器可以将[函数体](#函数声明)内声明但从未使用的变量视为非法。

在函数体内，可以省略变量的显式定义。

```xgo
d := math.Sin(0.5)  // d is float64
i := 42             // i is int
t, ok := x.(T)      // t is T, ok is bool
```
参见[短变量声明](#短变量声明)。

### 函数声明

函数声明将标识符（函数名）绑定到一个函数。

```text
FunctionDecl = "func" FunctionName Signature [ FunctionBody ] .
FunctionName = identifier .
FunctionBody = Block .
```
如果函数[签名](#函数类型)声明了结果参数，则函数体的语句列表必须以[终止语句](#终止语句)结尾。

```xgo
func IndexRune(s string, r rune) int {
	for i, c := range s {
		if c == r {
			return i
		}
	}
	// invalid: missing return statement
}
```
## 包

XGo 程序由多个包链接而成。每个包包含一个或多个源文件，它们共同声明该包的常量、类型、变量和函数，同包各文件均可访问这些声明。声明的实体可被[导出](#导出标识符)，供其他包使用。

### 源文件的组织

每个源文件先以包子句指定所属包，接着可以有一组导入声明，列出本文件希望使用的包，最后可以有一组函数、类型、变量和常量声明。后两组均可为空。

```text
SourceFile       = [ PackageClause ";" ] { ImportDecl ";" } { TopLevelDecl ";" } .
```
### package 子句

源文件以包子句开头，指明该文件所属的包。

```text
PackageClause  = "package" PackageName .
PackageName    = identifier .
```
PackageName 不能是[空白标识符](#空白标识符)。

```xgo
package math
```
### 导入声明

导入声明表示当前源文件依赖被导入包的功能（见[程序初始化与执行](#程序初始化与执行)），并使该包[导出](#导出标识符)的标识符可供本文件访问。导入声明通过 ImportPath 指定包，可以用标识符 PackageName 指定访问名称。

```text
ImportDecl       = "import" ( ImportSpec | "(" { ImportSpec ";" } ")" ) .
ImportSpec       = [ "." | PackageName ] ImportPath .
ImportPath       = string_lit .
```
导入该包的源文件在[限定标识符](#限定标识符)中使用 PackageName 访问导出标识符。PackageName 声明在[文件块](#代码块)中。省略时，默认采用所导入包的[包子句](#package-子句)中的名称。若显式使用句点 `.` 作为名称，被导入包[包块](#代码块)中声明的全部导出标识符都会在本文件的文件块中声明，使用时必须省略限定符。

ImportPath 的解释方式取决于实现。它通常是已编译包的完整文件名的一部分，也可以相对于已安装包的仓库定位。

实现限制：编译器可以要求 ImportPath 是非空字符串，并只使用 Unicode 通用类别 L、M、N、P、S 中的字符（即除空格外的图形字符），还可以排除下列字符：!"#$%&'()*,:;\&lt;=>?[\]^`&#123;|&#125;，以及 Unicode 替换字符 U+FFFD。

假设一个已编译的包声明为 `package math`，导出函数 `Sin`，安装位置为 `"lib/math"`。下表列出不同导入形式下如何在源文件中访问 `Sin`。

```xgo
Import declaration          Local name of Sin

import   "lib/math"         math.Sin
import m "lib/math"         m.Sin
import . "lib/math"         Sin
```
导入声明建立了导入方与被导入包之间的依赖关系。包不能直接或间接导入自身，也不能直接导入一个包却不使用其中任何导出标识符。若只需要包初始化的副作用，应显式使用[空白](#空白标识符)标识符作为包名。

```xgo
import _ "lib/math"
```

### 包初始化

包级变量分步初始化。每一步都在尚未初始化的变量中，选择*声明顺序*最靠前且不依赖尚未初始化变量的一项。

更确切地说，一个包级变量尚未初始化，并且没有初始化表达式，或其初始化表达式不依赖未初始化的变量时，就已就绪。每次初始化按声明顺序最靠前的就绪变量，直到没有就绪变量为止。

如果此时仍有变量未初始化，它们属于一个或多个初始化环，该程序无效。

如果变量声明的左侧有多个变量，右侧只有一个多值表达式，那么这些变量一起初始化。只要其中一个变量在某一步初始化，左侧的其他变量也都在同一步初始化。

```xgo
var x = a
var a, b = f() // a and b are initialized together, before x is initialized
```
包初始化时，声明中的[空白](#空白标识符)变量与其他变量同样处理。

跨文件的变量声明顺序由文件提交给编译器的顺序决定。第一个文件中的声明在第二个文件的所有声明之前，依此类推。为使初始化行为可复现，建议构建系统按文件名的字典序将同一个包的源文件提交给编译器。

依赖分析只依据源码中对变量的词法*引用*及其传递关系，无需知道变量的实际值。例如，变量 x 的初始化表达式引用一个函数，而函数体中引用变量 y，则 x 依赖 y。具体规则如下。

* 引用变量或函数，指使用了表示该变量或函数的标识符。
* 引用方法 m，指使用形式为 `t.m` 的方法值或方法表达式，其中 t 的静态类型不是接口，且 `m` 属于 `t` 的方法集。实际是否调用函数值 `t.m` 不影响依赖关系。
* 若变量 x 的初始化表达式或函数、方法 x 的函数体引用了变量 y，或者引用了依赖 y 的函数或方法，则 x 依赖 y。

例如，给定以下声明：

```xgo
var (
	a = c + b  // == 9
	b = f()    // == 4
	c = f()    // == 5
	d = 3      // == 5 after initialization has finished
)

func f() int {
	d++
	return d
}
```
初始化顺序是 `d`、`b`、`c`、`a`。子表达式在初始化表达式中的先后位置不影响这一顺序。本例写作 `a = c + b` 或 `a = b + c`，结果相同。

每个包独立分析依赖。只考虑对当前包声明的变量、函数及非接口方法的引用。如果变量之间还存在分析不可见的数据依赖，这些变量之间的初始化先后顺序没有规定。

例如，考虑以下声明（`TODO`：改用类文件演示，替换这里的方法示例）。

```xgo
var x = I(T{}).ab()   // x has an undetected, hidden dependency on a and b
var _ = sideEffect()  // unrelated to x, a, or b
var a = b
var b = 42

type I interface      { ab() []int }
type T struct{}
func (T) ab() []int   { return []int{a, b} }
```
变量 `a` 会在 `b` 之后初始化，但 `x` 究竟在 `b` 之前、在 `b` 与 `a` 之间，还是在 `a` 之后初始化，没有规定。因此 `sideEffect()` 在 `x` 初始化前还是初始化后执行也没有规定。

也可以通过包块中名为 `init` 的函数初始化变量。这些函数没有参数，也没有结果参数。

```xgo
func init() { … }
```
每个包可以定义多个这样的函数，同一源文件中也可以定义多个。在包块中标识符 `init` 只能用于声明 `init` 函数，标识符本身不会被[声明](#声明与作用域)。程序中无法显式引用这些函数。

初始化整个包时，先给所有包级变量赋初值，再按 `init` 函数在源码中的顺序调用它们。涉及多个文件时，以文件提交给编译器的顺序为准。

### 程序初始化

完整程序逐包初始化。先初始化当前包导入的各个包，再初始化当前包。一个包即使被多个包导入，也只初始化一次。包导入规则保证初始化依赖不可能成环。具体次序如下。

将所有包按导入路径排序。每一步从尚未初始化的包中，选取排序最靠前且所有被导入包均已初始化的一个包进行[初始化](#包初始化)。重复此步骤，直到所有包初始化完毕。

包初始化包括初始化变量及调用 `init` 函数，在同一个 goroutine 中按包依次进行。`init` 函数可以启动其他 goroutine，与初始化代码并发运行。各个 `init` 调用仍然严格串行，前一个返回后才会调用下一个。

### 程序执行

将一个未被其他包导入的主包与它直接或间接导入的所有包链接起来，就得到完整程序。主包的包名必须是 main，并且必须声明无参数、无返回值的函数 main。

```xgo
func main() { … }
```
程序先执行[程序初始化](#程序初始化)，然后调用 `main` 包的 `main` 函数。该函数返回后程序退出，不等待其他 goroutine 执行完毕。


### 运行时 panic

数组索引越界等执行错误会引发*运行时 panic*，相当于调用内置函数 [panic](#处理-panic)，其参数为实现定义的接口类型 `runtime.Error` 的值。此接口满足预声明接口 error。不同运行时错误条件对应的具体错误值没有规定。

```xgo
package runtime

type Error interface {
	error
	// and perhaps other methods
}
```
## 系统注意事项

### `unsafe` 包

编译器识别内置包 `unsafe`，可用[导入路径](#导入声明) `"unsafe"` 访问。该包提供底层编程操作，其中一些可以绕过类型系统。使用 unsafe 的包需要人工核查类型安全性，并且可能依赖平台。其接口如下。

```xgo
package unsafe

type ArbitraryType int  // shorthand for an arbitrary Go type; it is not a real type
type Pointer *ArbitraryType

func Alignof(variable ArbitraryType) uintptr
func Offsetof(selector ArbitraryType) uintptr
func Sizeof(variable ArbitraryType) uintptr

type IntegerType int  // shorthand for an integer type; it is not a real type
func Add(ptr Pointer, len IntegerType) Pointer
func Slice(ptr *ArbitraryType, len IntegerType) []ArbitraryType
func SliceData(slice []ArbitraryType) *ArbitraryType
func String(ptr *byte, len IntegerType) string
func StringData(str string) *byte
```
Pointer 是[指针类型](#指针类型)，但不能直接对 Pointer 值[解引用](#地址运算符)。任何指针或[底层类型](#底层类型)为 `uintptr` 的值都可以[转换](#类型转换)为底层类型为 Pointer 的类型，反向转换也成立。Pointer 与 `uintptr` 之间转换的效果由实现决定。

```xgo
var f float64
bits = *(*uint64)(unsafe.Pointer(&f))

type ptr unsafe.Pointer
bits = *(*uint64)(ptr(&f))

func f[P ~*B, B any](p P) uintptr {
	return uintptr(unsafe.Pointer(p))
}

var p ptr = nil
```
`Alignof` 和 `Sizeof` 接受任意类型的表达式 `x`。假设以 `var v = x` 声明变量 `v`，这两个函数分别返回 `v` 的对齐要求与大小。

`Offsetof` 接受选择器 `s.f`（可加圆括号）。其中 `f` 表示 `s` 或 `*s` 所代表结构体的字段。它返回相对于结构体起始地址的字段字节偏移。如果 `f` 是[嵌入字段](/zh-CN/docs/reference/full-specification#结构体类型)，则沿结构体字段访问它时不得经过指针间接寻址。对于具有字段 `f` 的结构体 `s`：

```xgo
uintptr(unsafe.Pointer(&s)) + unsafe.Offsetof(s.f) == uintptr(unsafe.Pointer(&s.f))
```
计算机体系结构可能要求内存地址*对齐*，即变量的地址必须是其类型的*对齐值*的整数倍。`Alignof` 接受任意类型变量的表达式，返回该变量类型以字节计的对齐值。对于变量 `x`：

```xgo
uintptr(unsafe.Pointer(&x)) % unsafe.Alignof(x) == 0
```
若 T 是类型参数，或者 T 是包含大小可变的元素或字段的数组或结构体，则 T 类型变量具有*可变大小*。其他情况下其大小为常量。如果 `Alignof`、`Offsetof` 和 `Sizeof` 的实参类型大小恒定（对 `Offsetof`，检查选择器 `s.f` 中结构体 `s` 的类型），则调用是类型为 `uintptr` 的编译期[常量表达式](#常量表达式)。

`Add` 将 `len` 加到 `ptr` 上，返回指针 `unsafe.Pointer(uintptr(ptr) + uintptr(len))`。`len` 必须为[整数类型](#数值类型)或无类型[常量](#常量)。常量 `len` 必须可用 `int` [表示](#可表示性)，无类型常量在这里取 `int` 类型。Pointer 原有的合法使用规则仍然适用。

`Slice` 返回一个切片，其底层数组从 `ptr` 开始，长度和容量均为 `len`。`Slice(ptr, len)` 等价于：

```xgo
(*[len]ArbitraryType)(unsafe.Pointer(ptr))[:]
```
有一个特例：如果 `ptr` 为 `nil` 且 `len` 为零，`Slice` 返回 `nil`。

`len` 必须为[整数类型](#数值类型)或无类型[常量](#常量)。常量 `len` 必须非负且可由 `int` [表示](#可表示性)，无类型常量在这里取 `int` 类型。运行时，若 `len` 为负数，或 `ptr` 为 nil 但 `len` 不为零，就会发生[运行时 panic](#运行时-panic)。

`SliceData` 返回指向 `slice` 底层数组的指针。若容量 `cap(slice)` 非零，结果是 `&slice[:1][0]`。若 slice 为 `nil`，结果为 `nil`。其他情况下返回非 nil 指针，其所指地址没有规定。

`String` 返回 `string` 值，其底层字节从 `ptr` 起始，长度为 `len`。对 `ptr` 和 `len` 的要求与 `Slice` 相同。若 `len` 为零，结果为空字符串 `""`。XGo 字符串不可变，调用后不得修改传给 `String` 的字节。

`StringData` 返回指向字符串 `str` 底层字节的指针。对于空字符串，返回值没有规定，可能为 `nil`。XGo 字符串不可变，不得修改 `StringData` 所指向的字节。

### 大小与对齐保证

[数值类型](#数值类型)的大小具有以下保证。

```xgo
type                                 size in bytes

byte, uint8, int8                     1
uint16, int16                         2
uint32, int32, float32                4
uint64, int64, float64, complex64     8
complex128                           16
```
对齐至少满足下列要求。

* 对于任意类型的变量 `x`，`unsafe.Alignof(x)` 至少为 1。
* 对于结构体变量 `x`，`unsafe.Alignof(x)` 等于各字段 `f` 的 `unsafe.Alignof(x.f)` 中的最大值，且至少为 1。
* 对于数组变量 `x`，`unsafe.Alignof(x)` 等于其元素类型变量的对齐值。

若结构体没有大小大于零的字段，或数组没有大小大于零的元素，则该类型的大小为零。两个不同的零大小变量可能具有相同的内存地址。

### 类型统一规则

类型统一规则描述两个类型能否统一、如何统一。它们关系到 XGo 的实现、错误消息的具体内容（例如报告类型推断错误还是其他错误），也有助于解释某些特殊代码的推断为何失败。编写一般 Go 代码时很少需要掌握这些细节。类型推断尽量符合直觉，统一规则也按此目标调整。

类型统一受匹配模式控制，分为*精确*与*宽松*。递归处理复合类型的结构时，元素通常沿用当前匹配模式。一个例外是按[可赋值性](#可赋值性)（≡A）统一两个类型：顶层宽松匹配，而元素类型精确匹配，因为可赋值的类型不一定相同。

当两个类型均非当前绑定的类型参数时，满足以下任一条件即可精确统一。

* 两个类型[相同](#类型标识)。
* 两个类型结构相同，且其元素类型精确统一。
* 恰有一个是具有[底层类型](#底层类型)的未绑定类型参数，该底层类型与另一个类型可以按 ≡A 规则统一（顶层宽松匹配，元素精确匹配）。

当两个类型都是已绑定的类型参数时，满足以下任一条件即可按给定模式统一。

* 两个类型参数相同。
* 至多一个类型参数已经有了已知的类型实参。此时把两个参数*联结*起来，共同表示同一个类型实参。若两者均无已知实参，之后为其中任意一个推断出的实参也同时适用于另一个。
* 两个类型参数都有已知实参，且这些实参可以按给定模式统一。

一个已绑定的类型参数 P 与另一个类型 T 在以下情形下可以按给定模式统一。

* P 没有已知类型实参。此时推断 T 为 P 的类型实参。
* P 的已知类型实参为 A，A 与 T 可按给定模式统一，且下列条件之一成立。
  * A 和 T 都是接口类型。如果两者又都是[定义类型](#类型定义)，则必须[相同](#类型标识)。若都不是定义类型，则它们的方法数量必须相同（A 与 T 的统一已确定这些方法能够匹配）。
  * A 和 T 均非接口类型。此时如果 T 是定义类型，就用 T 替换 A 作为 P 的推断类型实参。

最后，当两个类型均非已绑定的类型参数时，满足下列任一条件即可宽松统一，元素则按元素匹配模式处理。

* 两个类型精确统一。
* 其中一个是[定义类型](#类型定义)，另一个是非接口的类型字面量，并且二者的底层类型按照元素匹配模式统一。
* 两者都是接口（且均非类型参数），具有相同的[类型项](#接口类型)，并且同时嵌入或同时不嵌入预声明类型 [comparable](/zh-CN/docs/reference/full-specification#comparable-接口)。对应方法类型精确统一，其中一个接口的方法集是另一个接口方法集的子集。
* 两个类型中只有一个是接口（且非类型参数），对应的方法按元素匹配模式统一，并且接口的方法集是另一类型方法集的子集。
* 两个类型结构相同，且元素类型按元素匹配模式统一。
