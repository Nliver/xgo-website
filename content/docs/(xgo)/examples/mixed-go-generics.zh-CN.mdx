## 在同一个包中互相调用 Go 和 XGo

在 `demo/mixgo` 中运行。

对照阅读 `a.go` 和 `b.xgo`。Go 代码调用 XGo 函数 `sayMix`，XGo 代码则调用 Go 函数 `p`。仓库中的 `xgo_autogen.go` 由 `b.xgo` 生成。

### a.go

```go
package main

import "fmt"

func p(a any) {
	sayMix()
	fmt.Println("Hello,", a)
}
```

### b.xgo

```xgo
func sayMix() {
	println "Mix Go and XGo"
}

p "world"
```

### xgo_autogen.go

```go
// Code generated by xgo (XGo); DO NOT EDIT.

package main

import "fmt"

const _ = true
//line demo/mixgo/b.xgo:1:1
func sayMix() {
//line demo/mixgo/b.xgo:2:1
	fmt.Println("Mix Go and XGo")
}
//line demo/mixgo/b.xgo:5
func main() {
//line demo/mixgo/b.xgo:5:1
	p("world")
}
```

```sh
xgo run .
```

程序输出如下。

```text
Mix Go and XGo
Hello, world
```

## 将类型作为方法参数

在 `demo/typeasparamsmethod` 中运行。

### col.go

```go
package main

import (
	"fmt"
	"reflect"
)

type basetype interface {
	int | string
}

type Table struct {
}

func XGot_Table_XGox_Col__0[T basetype](p *Table, name string) {
	fmt.Printf("XGot_Table_XGox_Col__0 %v: %s\n", reflect.TypeOf((*T)(nil)).Elem(), name)
}

func XGot_Table_XGox_Col__1[Array any](p *Table, name string) {

```

```

```

## 运行测试类文件

在 `demo/unit-test` 中运行。

运行 `foo` 的测试。测试类文件检查一次直接调用，并定义了两个具名子测试。

### foo.xgo

```xgo
func foo(v int) int {
	return v * 2
}
```

### foo_test.gox

```xgo
if v := foo(50); v != 100 {
	t.error "foo(50) ret: ${v}"
}

t.run "foo -10", t => {
	if foo(-10) != -20 {
		t.fatal "foo(-10) != -20"
	}
}

t.run "foo 0", t => {
	if foo(0) != 0 {
		t.fatal "foo(0) != 0"
	}
}
```

```sh
xgo test -v .
```

程序输出如下。

```text
=== RUN   Test_foo
=== RUN   Test_foo/foo_-10
=== RUN   Test_foo/foo_0
--- PASS: Test_foo (0.00s)
    --- PASS: Test_foo/foo_-10 (0.00s)
    --- PASS: Test_foo/foo_0 (0.00s)
PASS
```
