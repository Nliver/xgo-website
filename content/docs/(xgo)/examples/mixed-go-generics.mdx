## Call between Go and XGo in one package

Run from `demo/mixgo`.

Read `a.go` and `b.xgo` together. Go calls the XGo function `sayMix`, while XGo calls the Go function `p`. The checked-in `xgo_autogen.go` is generated from `b.xgo`.

### a.go

```go title="a.go" verify="xgo run ."
package main

import "fmt"

func p(a any) {
	sayMix()
	fmt.Println("Hello,", a)
}
```

### b.xgo

```xgo title="b.xgo" verify="xgo run ."
func sayMix() {
	println "Mix Go and XGo"
}

p "world"
```

### xgo_autogen.go

```go title="xgo_autogen.go" verify="xgo run ."
// Code generated by xgo (XGo); DO NOT EDIT.

package main

import "fmt"

const _ = true
//line demo/mixgo/b.xgo:1:1
func sayMix() {
//line demo/mixgo/b.xgo:2:1
	fmt.Println("Mix Go and XGo")
}
//line demo/mixgo/b.xgo:5
func main() {
//line demo/mixgo/b.xgo:5:1
	p("world")
}
```

```sh
xgo run .
```

The program prints the following output.

```text
Mix Go and XGo
Hello, world
```

## Compile a mixed library package

Run from `demo/fullspec/mixgo-complex`.

Compile-check the package with `xgo test`. It contains Go and XGo implementations and a checked-in generated file.

### bar.go

```go title="bar.go" verify="xgo test ."
package main

import (
	"io"
	"log"
	"testing"
)

type ift interface {
	io.Closer
	f(int) string
	g()
}

type impl struct {
	a T
}

func Bar(t *testing.T) int {
	log.Println("Hello")
	t.Log("Hello",
		"world")
	return 0
}
```

### foo.xgo

```xgo title="foo.xgo" verify="xgo test ."

	"io"
	"log"
)

	f(int) string
	g()
}

	io.Closer
}

	log.println("Hi!")
	return
}

	_ = t.Closer
	return
}

	i.a.f(0)
	i.a.g()
	return ""
}

// foo golang/go#61561: interface instances aren't concurrency-safe
// as they are not completed by the type checker.

	return ""
```

## Inline function overloads

Run from `demo/fullspec/overloadfunc1`.

Call an overloaded function with integer arguments and then with string arguments.

### add.xgo

```xgo title="add.xgo"
func add = (
	func(a, b int) int {
		return a + b
	}
	func(a, b string) string {
		return a + b
	}
)

echo add(100, 7)
echo add("Hello", "World")
```

```sh
xgo run .
```

The program prints the following output.

```text
107
HelloWorld
```

## Define operators as methods and functions

Run from `demo/fullspec/overloadop1`.

Exercise the operator implementations in the order used by the program.

### overloadop.xgo

```xgo title="overloadop.xgo"

}

func (a foo) + (b foo) (ret foo) {
	echo "a + b"
	return
}

func (a foo) - (b foo) (ret foo) {
	echo "a - b"
	return
}

func (a foo) -> (b foo) {
	echo "a -> b"
}

func (a foo) <> (b foo) {
	echo "a <> b"
}

func -(a foo) (ret foo) {
	echo "-a"
	return
}

func ++(a foo) {
	echo "a++"
}

func (a foo) != (b foo) bool {
	echo "a != b"
	return true
}

var a, b foo
var c = a + b
var d = a - b
var e = -a
var f = a != b

echo f
a++
a -> b
a <> b
```

```sh
xgo run .
```

The program prints the following output.

```text

a - b
-a
a != b
true
a++

a <> b
```

## Run a test classfile

Run from `demo/unit-test`.

Run the tests for `foo`. The classfile checks a direct call and defines two named subtests.

### foo.xgo

```xgo title="foo.xgo" verify="xgo test -v ."
func foo(v int) int {
	return v * 2
}
```

### foo_test.gox

```xgo title="foo_test.gox" verify="xgo test -v ."
if v := foo(50); v != 100 {
	t.error "foo(50) ret: ${v}"
}

t.run "foo -10", t => {
	if foo(-10) != -20 {
		t.fatal "foo(-10) != -20"
	}
}

t.run "foo 0", t => {
	if foo(0) != 0 {
		t.fatal "foo(0) != 0"
	}
}
```

```sh
xgo test -v .
```

The program prints the following output.

```text
=== RUN   Test_foo
=== RUN   Test_foo/foo_-10
=== RUN   Test_foo/foo_0
--- PASS: Test_foo (0.00s)
    --- PASS: Test_foo/foo_-10 (0.00s)
    --- PASS: Test_foo/foo_0 (0.00s)
PASS
```
