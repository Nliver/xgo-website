XGo is a Go-compatible programming language designed for engineering, STEM education, and data science. Its syntax includes command-style function calls, string interpolation, and concise collection literals.

## Learning path

1. [Install XGo](/docs/getting-started/installation).
2. Run [your first program](/docs/getting-started/hello-world).
3. [Declare variables and format a greeting](/docs/tutorials/first-program).
4. [Define functions](/docs/tutorials/functions).
5. [Choose a branch and loop over a slice](/docs/tutorials/control-flow).
6. [Handle conversion errors](/docs/tutorials/error-handling).
7. Work with [strings, collections, and structs](/docs/reference/types).
8. [Use Go packages and mixed Go/XGo code](/docs/interoperability/go).

You can also try the external [Playground](/docs/toolchain/playground) or [REPL](/docs/toolchain/repl).
