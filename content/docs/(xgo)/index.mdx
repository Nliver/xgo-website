XGo is a programming language that reads like plain English. Its design brings existing code and libraries from C/C++, Go, Python, and JavaScript/TypeScript into a common software engineering ecosystem.

```text
XGo := C * Go * Python * JavaScript + Scratch
```

Our vision is to **enable everyone to become a builder of the world**.

## From a first program to a large project

A beginner can write a complete program in one line, `echo "Hello world"`. The same command-style calls appear in [SPX games](/docs/spx), where children familiar with Scratch can make sprites move and respond to events. In STEM education, students can start with those familiar ideas and learn a language they can later use at work.

For software engineers, XGo builds on Go's support for large projects. You can import existing Go packages and [write Go and XGo files in the same package](/docs/interoperability/go). Data scientists and engineers can work in the same language, using [LLGo](/docs/llgo/interoperability) to call C/C++ and Python libraries.

XGo calls its approach to specialized work *Specific Domain Friendliness*. For example, a game framework can give each sprite its own [classfile](/docs/toolchain/classfiles), so a game author can write the sprite's behavior directly in XGo. See [XGo versus Go](/docs/concepts/xgo-and-go) for more on the language's design.

## Learning path

1. [Install XGo](/docs/getting-started/installation).
2. Run [your first program](/docs/getting-started/hello-world).
3. [Declare variables and format a greeting](/docs/tutorials/first-program).
4. [Define functions](/docs/tutorials/functions).
5. [Choose a branch and loop over a slice](/docs/tutorials/control-flow).
6. [Handle conversion errors](/docs/tutorials/error-handling).
7. Work with [strings, collections, and structs](/docs/reference/types).
8. [Use Go packages and mixed Go/XGo code](/docs/interoperability/go).

You can also try the external [Playground](/docs/toolchain/playground) or [REPL](/docs/toolchain/repl).
