如果你想为 XGo 提交改动，请先阅读上游贡献指南。着手实现较大的改动前，先在 GitHub Issue 里讨论方案。除小修小补之外，指南要求把改动关联到已有的 Issue。

## 准备贡献

1. 阅读贡献指南和行为准则。
2. 在 GitHub 上 Fork 仓库，并将 Fork 与上游同步。
3. 为这项改动单独创建一个分支。
4. 检查改动，并在提交信息末尾加上 `Signed-off-by` 签署行。
5. 将分支推送到你的 Fork，再创建 Pull Request 供维护者审阅。

上游指南解释了提交消息和开发者来源证明（DCO）的要求。签署提交前，请先阅读这些要求。

## 报告文档问题

请提供页面 URL、使用的 XGo 版本、执行的命令和预期结果。附上一个简短的可复现程序，有助于维护者检查问题。
