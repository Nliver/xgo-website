## Class frameworks and tools

- [GSH](/docs/ecosystem/gsh) runs a shell command and captures its output from XGo.
- [HTML queries](/docs/ecosystem/hdq) show how to replace an HDQ query with built-in DQL.

See the [classfile guide](/docs/toolchain/classfiles) for the language mechanism these class frameworks use.
