The XGo repository links to **iXGo**, the official XGo REPL. Open the external service to explore XGo interactively.

[Open iXGo](https://repl.xgo.dev/)

For a complete program with a saved source file, use [Your first XGo program](/docs/getting-started/hello-world). The [Playground](/docs/toolchain/playground) provides another browser-based entry point.
