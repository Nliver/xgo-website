The upstream contribution guide describes how to propose changes to XGo. Discuss significant changes through an issue before starting implementation. Except for trivial changes, the guide asks contributors to relate their changes to an existing issue.

## Prepare a contribution

1. Read the contribution guide and code of conduct.
2. Fork the repository and synchronize your fork with upstream.
3. Create a branch for one focused change.
4. Check the change, then prepare a commit with a `Signed-off-by` trailer.
5. Push the branch to your fork and open a pull request for review.

The upstream guide explains commit messages and the Developer Certificate of Origin. Read those requirements before signing a commit.

[Read the XGo contribution guide](https://github.com/goplus/xgo/blob/c70869bd8cc9936c9fa2f3023566662c8963c49a/doc/contributing.md)

[Read the XGo code of conduct](https://github.com/goplus/xgo/blob/c70869bd8cc9936c9fa2f3023566662c8963c49a/CODE_OF_CONDUCT.md)

## Report a documentation problem

Include the page URL, the XGo version you used, the command you ran, and the result you expected. A small reproducible program helps maintainers check the issue.
