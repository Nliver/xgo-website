The XGo repository maintains two specifications. The Mini Specification describes the recommended syntax set. The Full Specification covers additional language features, including struct composite literals, and contains unfinished sections.

Use the versioned source links below when checking a language rule.

| Topic | Reference |
| --- | --- |

| Additional syntax and Go compatibility | [Full Specification](https://github.com/goplus/xgo/blob/c70869bd8cc9936c9fa2f3023566662c8963c49a/doc/spec.md) |
| Commands and function calls | [Function call guide](https://github.com/goplus/xgo/blob/c70869bd8cc9936c9fa2f3023566662c8963c49a/doc/fncall.md) |

For runnable introductions on this site, read [Functions](/docs/tutorials/functions), [Control flow](/docs/tutorials/control-flow), [Handle errors](/docs/tutorials/error-handling), [Types and values](/docs/reference/types), and [Go interoperability](/docs/interoperability/go).

This edition follows the source revision recorded with each page. It does not assign those materials to a stable XGo release. When reporting a discrepancy, include the page, source revision, toolchain version, and a small program that reproduces it.
