---
title: 安装 XGo
description: 安装 XGo 命令行工具，并运行一个小程序。
---

按你的操作系统选择安装方式。以下软件包安装命令来自 XGo 仓库。

## 准备 Go 工具链

在本地构建和运行 XGo 程序需要 Go 工具链。先安装 Go，再打开终端，确认能执行 `go` 命令。

```bash
go version
```

构建本文所用的 XGo 源码需要 Go 1.27.0 或与之兼容的更高版本。包管理器提供的 XGo 发行版可能不同，对 Go 的版本要求也可能不同。要使用与本文一致的版本，请参照下方的源码构建步骤。

## Windows

```bash
winget install goplus.xgo
```

## Debian 或 Ubuntu

上游给出的命令使用了 `trusted=yes`。即使软件源未通过身份验证，APT 也会将其视为可信。

添加软件源、更新软件包索引，再安装 XGo。

```bash
sudo bash -c ' echo "deb [trusted=yes] https://pkgs.xgo.dev/apt/ /" > /etc/apt/sources.list.d/goplus.list'
sudo apt update
sudo apt install xgo
```

## Red Hat、CentOS 或 Fedora

上游给出的命令使用了 `gpgcheck=0`，会关闭该软件源的软件包签名校验。

```bash
sudo bash -c 'echo -e "[goplus]\nname=XGo Repo\nbaseurl=https://pkgs.xgo.dev/yum/\nenabled=1\ngpgcheck=0" > /etc/yum.repos.d/goplus.repo'
sudo yum install xgo
```

## macOS 或 Linux（使用 Homebrew）

```bash
brew install xgo
```

## 从本文对应的源码版本构建

本文以 XGo 提交 `c70869bd8cc9936c9fa2f3023566662c8963c49a` 为准。该提交的根目录 `go.mod` 声明使用 Go 1.26.0，命令行工具的 `cmd/go.mod` 则要求 **Go 1.27.0**。构建命令行工具时，请使用 Go 1.27.0 或与之兼容的更高版本。

```bash
git clone https://github.com/goplus/xgo.git
cd xgo
git checkout c70869bd8cc9936c9fa2f3023566662c8963c49a
```

在 macOS 或 Linux 上运行以下构建脚本。

```bash
./all.bash
```

在 Windows 上运行以下批处理脚本。

```bat
all.bat
```

这两个脚本都会调用 `go run cmd/make.go`。

上游快速入门仍将最低版本写为 Go 1.19，与该提交的模块要求不一致。以上源码构建步骤以模块文件为准。软件包可能基于其他 XGo 提交构建。

## 验证安装

在终端中运行以下两条命令，确认 Go 和 XGo 都已安装。

```bash
go version
xgo version
```

如果终端提示找不到命令，请检查对应的安装目录是否已加入 `PATH`。接下来，按照[你的第一个 XGo 程序](/zh-CN/docs/getting-started/hello-world)创建 `hello.xgo`，再执行 `xgo run hello.xgo`。
